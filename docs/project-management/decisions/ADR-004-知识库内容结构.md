# ADR-004：知识库内容分为"知识拆解"和"考试指导"两部分

> 🔁 **【演进 · 2026-09-04】** 本决策的"知识拆解/考试指导双文档"已被 [ADR-012](./ADR-012-三层解耦与按知识点聚合.md) 演进为"一个官方知识点一篇、篇内固定 4 节（知识拆解/考试指导/题答解析/学员补充）"。本 ADR 作为历史决策保留，现行结构以 ADR-012 与 [KNOWLEDGE_BASE_TEMPLATE](../../development/templates/KNOWLEDGE_BASE_TEMPLATE.md) 为准。

> **状态**：已采纳
> **决策者**：用户 + AI

## 背景

课程视频和讲义的内容需要整理成知识库。最初考虑将所有内容放在一个文档中，但发现内容性质不同：一部分是知识本身（概念、原理、规则），另一部分是针对考试的指导（考点、记忆口诀、易错点、做题技巧）。

## 决策

每个章节的知识库内容分为两个独立文档：

1. **知识拆解**：知识本身，包括概念定义、原理说明、规则解释、知识体系
2. **考试指导**：针对考试的内容，包括考点标注、记忆口诀、易错点、做题技巧、真题解析

**目录结构**：
```
01税法总论/
├── 知识拆解.md      ← 知识本身
├── 考试指导.md      ← 针对考试
└── README.md        ← 章节索引，包含两个文档的链接
```

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| 单一文档（所有内容混合） | 结构简单 | 内容混乱，难以区分知识和考试技巧 |
| **两个文档（知识拆解+考试指导）** | **内容清晰，用途明确，便于搜索和问答** | **需要维护两个文档，内容可能有重叠** |
| 三个文档（知识+考点+技巧） | 更细分 | 维护成本高，内容碎片化 |
| 按视频课时分文档 | 与原始内容对应 | 知识体系被打散，难以形成完整知识网络 |

## 决策理由

1. **用途不同**：知识拆解用于学习和理解概念，考试指导用于备考和做题
2. **搜索友好**：用户搜索"税法原则"时找到知识拆解，搜索"考点"时找到考试指导
3. **AI问答友好**：AI可以根据问题类型选择参考哪个文档
4. **内容性质不同**：知识相对稳定，考试指导需要根据考情更新
5. **用户需求**：用户明确提出"知识是为了应用和搜索，考试指导是为了备考"

## 后果

### 正面
- 内容结构清晰，用途明确
- 便于搜索和AI问答
- 知识和考试技巧可以独立更新

### 负面
- 需要维护两个文档
- 部分内容可能有重叠（如重要考点既是知识也是考试重点）
- 生成知识库时需要分别整理两个文档

## 内容重叠处理原则

1. **知识拆解**：只放知识本身，不放考试技巧
2. **考试指导**：可以引用知识拆解中的重要概念，但重点放在考点、记忆口诀、易错点
3. **重要考点**：在知识拆解中标注"考点"，在考试指导中详细展开
4. **用户笔记与知识冲突时**：以知识拆解为准
