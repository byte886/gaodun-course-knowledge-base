## 一、核心原则

### 1.0 知识本身与考试指导分离

每个讲座的内容拆分为两个独立文档：

| 文档 | 内容 | 用途 | 本地文件名 | 知识库节点名 |
|------|------|------|-----------|-------------|
| **知识拆解** | 知识本身（定义、特征、分类、表格、结构化知识点） | 应用、搜索、AI问答 | `知识拆解.md` | `知识拆解` |
| **考试指导** | 考试指导（考点、易错点、记忆口诀、真题、考情、学习建议） | 备考、应试 | `考试指导.md` | `考试指导` |

> **命名规范**：完整命名规范见 [NAMING_CONVENTION.md](../../project-management/standards/NAMING_CONVENTION.md)。所有本地文件和知识库节点必须统一使用中文命名（知识拆解、考试指导），禁止使用英文命名（knowledge.md、exam-guide.md）。

**为什么分离**：
- 知识本身用于应用和搜索，应该纯净、结构化，不受考试内容干扰
- 考试指导用于备考，包含考点、易错点、真题等，目标不同
- 拆分后更有利于AI检索和问答（知识本身更纯净）
- 两者可以独立更新，互不影响

**分离原则**：
- 知识本身：只保留客观知识点，不包含"考点提示""易错点""记忆口诀""真题回顾"等考试指导内容
- 考试指导：收集所有考试相关内容，按"考情分析→高频考点→易错点→记忆口诀→真题回顾→学习建议"组织
- 两个文档互相引用：知识本身末尾注明"考试指导请查看 考试指导.md"，考试指导开头注明"知识本身请查看 知识拆解.md"

**新知识点补充原则（重要）**：
- 在做题、收集解析、整理用户留言等任何过程中，如果发现**新的知识点**（无论是考试指导相关的，还是非指导考试的），都必须补充到**知识拆解**文档中
- **非指导考试的知识点**（如知识的背景、扩展应用、跨学科联系、实际案例等）同样需要补充到知识拆解中，不能因为"不直接考"就忽略
- 知识拆解的目标是构建**完整的知识体系**，不仅服务于考试，也服务于知识应用、搜索和AI问答
- 补充新知识点时，按知识拆解的结构组织（定义、特征、分类、表格、结构化知识点），不添加考试指导内容
- 考试指导相关的内容（考点、易错点、记忆口诀、真题）补充到考试指导文档中
- **检查时机**：每次完成做题、收集解析、整理用户留言后，必须检查是否有新知识点需要补充到知识拆解

**冲突处理原则（重要）**：
- 当用户笔记（用户留言、用户总结）与知识库拆解（知识拆解文档）出现冲突时，**以原知识库（知识拆解）为准**
- 用户笔记可能存在个人理解偏差、记忆错误、过时信息等问题，不能直接覆盖知识库内容
- 如果用户笔记中包含知识库没有的新知识点，且经过验证准确，则补充到知识拆解中
- 如果用户笔记与知识库内容冲突，需要进一步验证（查阅讲义、官方解析、权威来源），确认知识库有误后才修正知识库
- **验证顺序**：讲义/官方教材 > 官方解析 > 高赞用户笔记 > 普通用户笔记
- 未经验证的用户笔记内容，不得直接修改知识库拆解

### 1.0.1 父页面（目录页）规范

每个父节点（课程节点或章节节点，如01税法总论）作为目录页，必须包含以下内容：

**适用范围**：
- 课程节点（如【26考季】VIPCPA系列-税法）
- 章节节点（如01税法总论、02增值税法）

**必须包含**：
1. **基本信息块**：课程/章节名称、主讲老师、整理来源、适用范围、更新时间
2. **子节点目录清单**：知识拆解和考试指导两个子文档的可点击链接，每个链接附带简要说明
3. **章节概述**：简要介绍本章节的主要内容和学习目标
4. **重点内容**：列出本章节的核心知识点（3-7条）
5. **学习建议**：给出学习顺序和方法建议

**不包含**：
- 正文知识点内容（父页面只是目录，不承载知识内容）
- 重复的章节框架（子文档中已有）
- 文档维护说明（这是流程相关文档需要记录的，不放在知识库中）

**模板**：
```markdown
# [章节名称]

> 课程：2026 CPA 税法-全面精讲 | 主讲：蔡俊峻老师
> 整理来源：视频转写 + 讲义文档 + 用户留言精华
> 适用范围：CPA税法考试备考
> 更新时间：2026-08-28

---

**为什么需要父页面目录清单**：
- 用户打开父节点时，直接看到可点击的子文档链接，不需要从左侧目录树查找
- 对外分享时，访问者能直接看到章节结构和入口
- AI检索时，父页面作为索引页，帮助AI理解章节结构
- 子文档内容过多时，可进一步拆解为多个子文档，父页面目录清单同步更新

**子文档拆解原则**：
- 当知识拆解或考试指导内容过多（超过5000字或超过10个一级标题）时，可考虑拆解
- 拆解后，父页面目录清单应更新，列出所有子文档的链接和说明
- 拆解应按知识点或考点进行，保持逻辑清晰

### 1.1 Answer-First（答案优先）

每节/每段开头直接给出核心答案或结论，再展开背景和解释。

**为什么**：AI检索系统优先提取开头内容，答案在前能提高AI回答的准确率。

**示例**：
```
### 税收法定原则

税收法定原则是税法基本原则的核心，包括税收要件法定和税务合法性两个方面。

【展开解释】...
```

### 1.2 Atomic Structure（原子结构）

每段内容专注回答一个具体问题或知识点，不混合多个主题。

**为什么**：模块化内容让AI能精确检索到需要的段落，减少幻觉。

**反例**：一段同时讲"税收法定原则"和"税收公平原则"
**正例**：分两段，每段一个原则

### 1.3 Strict Hierarchy（严格层级）

严格使用 H1/H2/H3 层级，不跳级（H2不跳到H4）。

**为什么**：层级结构帮助AI理解信息的范围和从属关系，正确加权信息。

**层级规范**：
- H1：文档标题（如"第一章 税法总论"）
- H2：节（如"第一节 税法的概念"）
- H3：知识点（如"一、税收与现代国家治理"）
- H4：子知识点（如"税收定义"）

### 1.4 Context Block（上下文块）

每篇文档开头添加元数据块，说明适用范围、来源、更新时间等。

**为什么**：AI需要知道内容的适用条件，才能给出准确的、有过滤的答案。

**模板**：
```
> 课程：2026 CPA 税法-全面精讲 | 主讲：蔡俊峻老师
> 整理来源：视频转写（X字）+ 讲义OCR（X页）
> 考情：基础理论知识，非重点内容，题型均为选择题，预计分值2-2.5分
> 适用范围：2026考季CPA税法备考
> 更新时间：2026-08-27
```

### 1.5 MECE分类

分类互斥（Mutually Exclusive）且穷尽（Collectively Exhaustive），避免重叠和遗漏。

**为什么**：重叠分类会让AI检索时重复提取，降低准确率；遗漏则会导致答案不完整。

**检查方法**：
- 每个知识点只属于一个分类
- 所有知识点都能归入某个分类

### 1.6 飞书Aily知识空间6原则

参考飞书Aily智能体知识空间设计原则（来源：[飞书服务台→Aily 知识空间:AI 知识库搭建规则与升级指南](http://m.toutiao.com/group/7604847920693559846/)）：

| 原则 | 说明 | 在本项目的应用 |
|------|------|----------------|
| 一题一段 | 一条知识只包含一个明确主题 | 每个知识点独立成段，不混合多个主题 |
| 口语对齐 | 标题就是用户怎么问，同义句用","分隔 | 知识拆解的标题使用用户可能的提问方式 |
| 300令牌 | 答案≤300 token（约450字），超长拆多条 | 每个知识点控制在450字以内，过长则拆分 |
| 时效可见 | 必填生效/失效日期，过期自动下沉 | 考试指导中标注考季和适用时间（如"26考季"） |
| 层级分类 | ≤3层，便于向量过滤 | 知识库目录结构控制在3层以内（课程/章节/知识点） |
| 0敏感 | 去除工资、身份证、权限操作，统一"请联系 HR/IT" | 知识内容中不包含个人敏感信息 |

## 二、文档结构模板

### 2.1 标准知识梳理文档结构（双文档分离）

每个讲座拆分为两个文档：

#### 文档A：知识拆解.md（知识本身）

```
# [章节标题]

> [Context Block：课程/主讲/来源/适用范围/更新时间/文档类型/配套文档]

## 本章框架
[树形结构大纲]

## 第一节 [节标题]

### 一、[知识点1]
[Answer-First：核心结论]
[展开解释]
[表格/对比]

### 二、[知识点2]
...

...

> 本文档为知识本身（结构化知识点），适用于搜索、应用、AI问答。考试指导内容请查看配套文档 考试指导.md。
```

#### 文档B：考试指导.md（考试指导）

```
# [章节标题] - 考试指导

[章节定位、题型、预计分值、学习策略]

[按节整理高频考点]

## 易错点
[按节整理常见错误]

## 三、AI问答优化建议

### 3.1 增加FAQ部分

每章末尾增加常见问题解答，格式为"问题+答案"，方便AI问答系统直接匹配。

**示例**：
```
## 常见问题

Q: 税法与行政法的区别是什么？
A: 税法是行政法的分支，但具有两个行政法不具备的特征：①经济分配性质（纳税人向国家无偿单方面转移）；②义务性法规（行政法大多是授权性法规）。

Q: 区别一种税与另一种税的重要标志是什么？
A: 征税对象（课税对象）是区别一种税与另一种税的重要标志。
```

### 3.2 关键词和标签

文档中明确标注关键词，方便AI检索和用户搜索。

**示例**：
```
关键词：税收法定原则、税法基本原则、税收公平、税收效率、实质课税
```

### 3.3 交叉引用

相关知识点之间建立交叉引用，帮助AI理解知识关联。

**示例**：
```
> 相关知识点：[税收法律关系](#税收法律关系)、[税法要素](#税法要素)
```

## 四、知识库目录结构规范

### 4.1 层级深度

- 不超过3层深度（参考飞书最佳实践）
- 一级分类：CPA
- 二级分类：课程库/待整理
- 三级分类：课程名称
- 四级：讲座标题（文档页面）

### 4.2 命名规范

- 课程名称：【XX考季】VIPCPA系列-XX（XX老师）
- 章节标题：严格对齐官方课程讲次标题，不擅自修改、合并或重排
- 示例：税法全面精讲01-税法总论、税法全面精讲02-消费税法（1）
- 跨税种讲保持讲次完整性，在章节内按税种分段组织
- 具体课程的讲次映射表作为任务执行数据，不写入本规范文档

## 五、质量检查清单

每次生成知识梳理文档后，按以下清单检查：

| 检查项 | 标准 |
|--------|------|
| **父页面规范** | 课程节点（父页面）包含课程信息块和子节点链接，不包含正文内容 |
| **双文档分离** | 知识拆解.md（知识本身）和 考试指导.md（考试指导）已分离 |
| **知识拆解.md 纯净性** | 不包含考点提示、易错点、记忆口诀、真题回顾等考试指导内容 |
| **考试指导.md 完整性** | 包含考情分析、高频考点、易错点、记忆口诀、真题回顾、学习建议 |
| **互相引用** | 两个文档末尾互相注明配套文档 |
| Context Block | 包含课程/来源/适用范围/更新时间/文档类型 |
| 本章框架 | 知识拆解.md 有树形结构大纲 |
| Answer-First | 知识拆解.md 每节开头有核心结论 |
| 层级规范 | H1/H2/H3/H4严格层级，不跳级 |
| 原子结构 | 每段一个主题，不混合 |
| MECE分类 | 分类互斥且穷尽 |
| 表格对比 | 关键对比内容用表格 |
| 本章总结 | 考试指导.md 有高频考点/易错点/学习建议 |
