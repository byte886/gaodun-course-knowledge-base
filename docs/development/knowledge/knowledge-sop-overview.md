## 各文档职责边界（防重叠）

| 文档 | 只管什么 | 不管什么 |
|------|---------|---------|
| **组织规范** | 结构、分组、三层解耦、范式 | 具体怎么写内容、具体格式 |
| **写作风格指南** | 怎么写好内容、四节结构、格式规范、质量标准 | 怎么组织章节、怎么同步飞书 |
| **生成SOP** | 多智能体协作流程、生成步骤、样板门 | 具体写什么内容、具体怎么同步 |
| **飞书同步SOP** | 建树、同步流程、限流、错误恢复 | 内容写得好不好、链接对不对 |
| **内容验证SOP** | 同步后内容完整性验证 | 同步流程本身 |
| **链接验证SOP** | 同步后链接有效性验证 | 同步流程本身 |
| **知识库模板库** | 具体格式模板（章/知识点/全局篇） | 为什么要这样组织 |

## 新AI上手三步（按顺序）

1. **第一步**：先看本总览，搞清楚整个流程有哪几个环节
2. **第二步**：看你当前要做的那个阶段的文档（从上面快速导航找）
3. **第三步**：遇到问题，按文档里的"相关文档"链接找下钻

## 核心原则（所有文档共同遵守）

1. **本地是唯一源头**：所有内容先在本地写好，再同步飞书，禁止直接改飞书
2. **一个知识点一篇**：按官方知识点聚合，一篇一个知识点
3. **一篇四节**：知识拆解 / 考试指导 / 题答解析 / 学员补充
4. **多智能体协作**：生成和检查分离，避免"自己写自己查"
5. **每课必做深度审核**：一个课程完整结束后，立刻做深度质量审核，不跳着做
