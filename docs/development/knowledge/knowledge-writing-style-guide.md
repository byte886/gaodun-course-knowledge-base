# 知识详解统一写作风格指南（六科通用）

> **文档类型**：Governance（写作规范 — 六科知识详解统一标准）
> **更新频率**：风格规范变更时
> **维护者**：AI自动维护 + 用户审核
> **读者**：AI代理（生成/优化知识详解时必须遵守）
> **适用范围**：名师专业课六科（会计/审计/财管/税法/经济法/战略）所有知识详解成品

> 本指南基于会计、审计两科的成熟实践，结合项目SOP（knowledge-base-organization.md、KNOWLEDGE_BASE_TEMPLATE.md）和专业写作规范（Diátaxis四分类、9C质量特征、倒金字塔、认知负荷管理）制定。所有六科知识详解必须统一遵循本指南。

> **相关SOP**：生成流程与多智能体协作见 [knowledge-detail-build-sop.md](../guides/knowledge-detail-build-sop.md)

## 零、可读性优化五原则（2026-09-17起强制执行）

> 用户反馈：早期版本内容简洁易读，当前版本内容过多、过密、阅读疲劳。基于此反馈，新增以下五原则，所有新生成和优化的知识详解必须遵守。

### 0.1 结构清晰
- 每节（H2）开头必须增加「**本节要点**」引用块摘要（3-5条核心结论），让读者快速抓住重点
- 摘要只列结论，不展开细节；细节在正文中展开
- 示例：
  ```markdown
  ## 一、知识拆解
  
  > **本节要点**：
  > - 会计是以货币为主要计量单位的经济管理工作
  > - 两大基本职能：核算和监督
  > - 会计人员职业道德：三坚三守（诚信/准则/学习）
  ```

### 0.2 语言简练
- 精简冗余描述，删除"也就是说"、"换句话说"、"需要注意的是"等过渡词
- 用表格、对比、列表替代大段文字；每段不超过3-4行
- 避免重复：同一概念不在多个小节重复解释，首次出现时详细解释，后续引用即可
- 公式、定义、结论用独立行或引用块突出，不埋在大段文字中

### 0.3 图文并茂
- **优先使用表格**：对比（A vs B）、分类列举（>3项）、多维度信息（定义+标准+特点）必须用表格
- **对比表**：易混概念、新旧准则、不同处理方法必须用对比表
- **流程图**：业务流程、计算步骤、决策逻辑用文字版流程图（用箭头和编号表示）
- **思维导图结构**：复杂知识体系用层级列表（H3/H4）呈现，模拟思维导图
- 避免纯文字堆砌；连续超过3段纯文字时，考虑用表格或列表重构

### 0.4 重点突出

#### 标签白名单（强制，禁止自造）

所有标注标签必须从以下白名单中选择，禁止使用【考点】【重点】【高频考点】【易错对比】【易错辨析】等自造标签。

**三级考试频率标签（互斥，每个知识点只能选一个）**：
- `【必考】` — 近5年每年必考，必须掌握，核心中的核心
- `【高频】` — 近5年考过3次以上，重点掌握
- `【了解】` — 近5年考过0-2次，了解即可，非重点

**辅助标签（可与频率标签叠加）**：
- `【易错】` — 容易出错的地方，**必须与「考试指导」节的易错点汇总表双向挂钩**（汇总表中有的条目，正文对应节必须加【易错】标注）
- `【新增】` — 当年教材新增或修订内容，需在考情速览中说明命题规律
- `【记忆】` — 记忆口诀、记忆方法、对比记忆，帮助快速记忆

**标签使用规则**：
1. 每个H3知识点开头的【核心结论】前，必须加一个频率标签（【必考】/【高频】/【了解】）
2. 易错点在正文对应位置加【易错】标注，同时在「考试指导」节易错点汇总表中列出
3. 新增内容加【新增】标注，同时在考情速览中说明
4. 记忆口诀加【记忆】标注，同时在「考试指导」节记忆口诀部分列出
5. 禁止在标签中夹带元数据（如"这是历年高频考点"不是标签，是废话）
6. 标签必须放在句首或段首，不能插在句子中间

- 用**粗体**突出关键结论、数字、术语
- 易错点统一用❌→✅对比表格式（见 §五）
- 高频考点在「考试指导」节用表格形式，逐条一个可考点

### 0.5 分层阅读
- **Answer-First原则**：每个H3子主题开头先给核心结论（一句话），再展开背景和细节
- 核心结论前置，详细解释后置；满足不同深度的阅读需求
- 读者可以只看「本节要点」+ 每个H3的核心结论，就能掌握80%的内容
- 需要深入学习时，再阅读展开部分和例题

### 0.6 同主题分多篇的边界规范（防重叠）

当一个主题拆成多篇时（如"长期股权投资转换"分增持/减持/处置），每篇必须：

1. **开头加「本篇范围」说明**（引用块）：
   - 明确本篇讲哪几种情况
   - 明确哪些内容在其他篇讲，本篇不重复展开

2. **跨篇引用格式统一**：
   - 用「详见《XX篇》」引用，不重复展开细节

**示例**：
> **本篇范围**：本文讲"股权减持导致的转换"（成本法→权益法、权益法→公允价值计量）。
> 股权增持的转换见《长期股权投资转换（股权增持）》；处置见《长期股权投资处置》。

### 0.6.1 难点知识点强制对比表（硬要求）

**适用场景**（满足任一即触发）：
- 一个知识点包含 **3种及以上情况/场景/方案** 时（如长投转换3种情况、金融资产3分类）
- **易混概念横向对比** 时（如控制 vs 共同控制 vs 重大影响）

**强制要求**：
- 必须做**横向对比表**，列出所有情况的关键维度（适用场景、会计处理、差额处理、影响科目等）
- **不能只靠纯文字逐个描述**——纯文字不利于横向对比记忆
- 对比表放在"本节要点"之后、详细展开之前

**示例（长投转换）**：
| 转换类型 | 个别报表处理 | 合并报表处理 | 差额计入 |
|---------|-------------|-------------|---------|
| 成本法→权益法（减持） | 追溯调整 | 剩余股权按公允价值重新计量 | 投资收益 |
| 权益法→公允价值（减持） | 原持股比例部分转入其他综合收益 | 同个别报表 | 其他综合收益转投资收益 |
| 成本法→公允价值（减持） | 剩余股权按公允价值计量 | 同个别报表 | 投资收益 |

### 0.7 文件名规范（硬要求）

**1. 序号前缀**：
- 每个知识点文件必须带**两位序号前缀**（01_、02_...），按学习顺序编号
- 序号与章README表格里的序号一一对应
- 作用：保证飞书知识库目录树按学习顺序自动排序
- 正确示例：`01_基本概念.md`、`02_合营安排.md`
- 错误示例：`基本概念.md`、`合营安排.md`（无序数，排序混乱）

**2. 括号规范**：
- 文件名里的括号必须用**中文全角括号**（），不能半角全角混用
- 作用：避免相对链接解析失败
- 正确示例：`长期股权投资转换（股权增持）.md`
- 错误示例：`长期股权投资转换（股权增持).md`（左全角右半角，链接解析失败）

## 一、frontmatter 规范

### 1.1 格式统一

- 使用**紧凑格式**（一行多字段），不使用展开格式（每字段单独一行）
- 字段顺序固定：`type` → `title` → `description` → `tags` → `sources` → `generated` → `status` → `stale_after` → `chapter` → `exam_season` → `teachers` → `point_id`

### 1.2 标准字段（必填）

| 字段 | 格式 | 示例 |
|------|------|------|
| `type` | 三词表之一 | `KnowledgePoint` / `ChapterIndex` / `Reference` |
| `title` | 简洁，不超过30字，不含括号细节 | `"合并范围的确定"` |
| `description` | 100-150字，一句话定位+核心要点，不展开细节 | 见 §1.3 |
| `tags` | 英文slug紧凑数组 | `[cpa, accounting, 26-season, chapter-29]` |
| `sources` | 标准id+resource+title | 见 §1.4 |
| `generated` | `{ by: process:knowledge-build, at: ISO时间 }` | - |
| `status` | `draft` / `stable` | - |
| `stale_after` | `2027-03-31T23:59:59+08:00` | - |
| `chapter` | `NN_章名` | `29_合并财务报表` |
| `exam_season` | `2026` | - |
| `teachers` | 数组 | `[姚远, 陈蓓蓓]` |
| `point_id` | 数字 | `29001` |

### 1.3 description 写作规范（重点）

**长度**：100-150字（约2-3句话）

**结构**：
1. 第一句：知识点定位（所属章、跨几讲、在考试中的地位）
2. 第二句：核心要点（3-5个关键词，用顿号分隔）
3. 第三句（可选）：特殊说明（新增/变更/易错提示）

**示例（好）**：
> "29_合并财务报表知识点、跨2讲。控制的定义三要素（权力+可变回报+运用权力影响回报）、被投资方设立目的分析、权力判断（实质性权利vs保护性权利、表决权与合同安排）、可变回报形式、代理人与主要责任人、投资性主体豁免。2023/2024年真题考点。"

**反例（差）**：
> 超过300字，逐条展开每个子主题的细节，与正文重复

### 1.4 sources 规范

- 每条必须含 `id` + `resource` + `title` 三字段
- `id` 用英文slug：`handout-{老师}` / `transcript-{老师}-{讲次}` / `paper-{id}`
- `resource` 著录到讲目录或文件，不指单个易改名PDF
- 无题（名师课/风控期）**不写** `question_count` 字段（整行省略，不写0）

### 1.5 禁止字段

- 禁止 `question_count: 0`（无题时整行省略）
- 禁止非标准扩展字段（如 `point_count`、`scope` 等，如需扩展先更新本指南）
- 禁止中文tags（必须用英文slug）

## 二、标题层级规范

### 2.1 层级结构

```
# H1：官方知识点名（不带point_id前缀）
## H2：固定四节（一、知识拆解 / 二、考试指导 / 三、题答解析 / 四、学员补充）
### H3：节内子主题（用"1. 标题"格式）
#### H4：子主题下的细分（必要时用，不跳级）
```

### 2.2 编号统一

- H3统一用 **`### 1. 标题`** 格式（数字+点+空格）
- 不使用 `### （一）标题`、`### 1)`、`**1. 标题**` 等其他格式
- H4如需要可用 `#### （1）标题` 格式

### 2.3 H1规范

- H1 = 官方知识点原名，**不带point_id前缀**
- 正确：`# 合并范围的确定`
- 错误：`# 29001 合并范围的确定`

## 三、Context Block 规范

每篇开头（H1之后、H2之前）必须有引用块Context Block，格式统一：

```markdown
> 所属组：NN_章名
> 来源：视频字幕转写 N 讲（老师 讲次）· 讲义全一册 1 份（第X章第X节）
> 适用：2026 考季 CPA {科目}
> 更新：YYYY-MM-DD
> 说明：本篇为名师课来源融合稿；题答受账号风控（10462221）冻结，待解除后回补，当前 status=draft。
```

- 五行固定，顺序不变
- 来源行根据实际来源调整（如只有讲义则只写讲义）
- 说明行统一风控占位话术

## 四、四节内容写作规范

### 4.1 第一节：知识拆解

**定位**：客观知识，定义/特征/分类/原则/表格/结构化要点

**写作原则**：
- **Answer-First**：每个H3子主题开头先给核心结论（一句话），再展开背景
- **Atomic Structure**：每段只讲一个具体问题，不混合多个主题
- **表格优先**：对比、分类、列举用表格呈现，减少大段文字
- **公式独立**：可复用的公式/规则/对照表放本节，不与题答解析重复

**教材例题处理**：
- 教材例题用 `**【教材例X-Y】**` 加粗标注
- 例题题干用普通文本，解析用 `**【解析】**` 开头
- 例题与正文知识用空行分隔，视觉上明显区分
- 例题较多时（>3个），可在该知识点末尾设 `### N. 教材例题汇总` 小节

### 4.2 第二节：考试指导

**定位**：考情、高频、易错、口诀、技巧

**固定子结构**（H3）：
1. `### 1. 考情` — 考试地位、频次、题型、分值
2. `### 2. 高频考点` — 编号列表，逐条一个可考点
3. `### 3. 易错点` — **统一用❌→✅对比表**（见 §五）
4. `### 4. 答题技巧` — 做题步骤、排雷顺序、口诀

**易错点表格格式**（强制统一）：

```markdown
| 易错点 | 正确处理 |
|--------|----------|
| ❌{常见错误表述} | ✅{正确结论} |
```

### 4.3 第三节：题答解析

**定位**：本知识点全部题：题面/选项/标准答案/官方解析

**格式规范（统一版本，本地=飞书一致）**：
- **题目前缀只保留题型**：`1.（多选）`、`2.（单选）`、`3.（大题）`
- **正文不出现技术信息**：paperId、来源卷等技术信息统一放frontmatter的`sources`字段，不放正文里
- **本节要点里**："paper题"改成"真题"，不出现技术词汇
- **真题保留年份标注**：如【真题·2017·多选题】可保留
- **正确示例**：`**1.（多选）下列股权投资中...**`
- **错误示例**：`**1.【多选｜来源：【26-精讲】会计-知识点练习-基本概念（paperId 82243）】下列股权投资中...**`

> **设计原则**：本地是唯一源头（AGENTS.md 3.8），正文统一写成考生友好版；AI需要paperId等技术信息时，从frontmatter的sources字段读取，不从正文读。不维护"内部版/外部版"两个版本。

**风控期占位**（统一话术）：
```markdown
> 本篇完整题答依赖做题 / 只读开卷链路，当前因账号风控错误码 10462221 被冻结。**待风控解除后**用 `fetch_ep3_paper_readonly.js --done-only` 回补并将 status 由 draft 升为 stable。
>
> 已从课件见到的本知识点题（课件已附参考答案要点）：
> - **{年份} {题型}·{主题}**：{核心考点与答案要点}
```

### 4.4 第四节：学员补充

- 无高价值学员内容时**整节省略**（不保留空标题）
- 有内容时标注来源，与正文冲突按权威度处理

### 4.5 关联知识点（固定导航节）

- 位置：第三节之后、第四节之前（如无第四节则在末尾）
- 格式：`## 关联知识点` + 项目符号列表，含相对链接和一句关联说明
- 兄弟篇尚未生成可挂前向链接（文件名取官方点名）

## 五、易错点格式规范（强制统一）

所有六科的"易错点"必须使用 **❌→✅对比表** 格式：

```markdown
### 3. 易错点

| 易错点 | 正确处理 |
|--------|----------|
| ❌以出库单为起点做截止测试对所有企业都适用 | ✅起点要匹配**收入确认时点**，验收后确认收入的要用**验收单** |
| ❌顺查（凭证到账）用来查虚增收入 | ✅顺查查**完整性（漏记）**；**逆查（账到凭证）才查发生（虚增）** |
```

**要求**：
- 表格两列固定：`易错点` / `正确处理`
- 错误表述前加 `❌`，正确结论前加 `✅`
- 每条只讲一个易错点，不混合
- 关键词加粗

## 六、表格使用规范

**何时用表格**：
- 对比（A vs B）
- 分类列举（>3项）
- 多维度信息（定义+标准+特点）
- 易错点（强制）

**表格原则**：
- 表头简洁，不超过10字
- 单元格内容尽量短，长内容用项目符号
- 同列格式统一（如都用"是/否"、都用数字）
- 表格前后留空行

---

## 七、认知负荷管理

1. **短段落**：每段不超过3-4行，超过则拆分
2. **留白**：大段文字之间用空行或引用块分隔
3. **关键词加粗**：核心术语、数字、结论用 `**加粗**`
4. **避免大段同质文本**：连续超过3段纯文字时，考虑用表格或列表重构
5. **信息密度控制**：单个表格单元格不超过50字，超过则拆分

## 八、科目特定规范

### 8.1 会计
- 分录格式：`借：科目 金额` / `贷：科目 金额`，借贷对齐
- 教材例题保留完整（例X-Y编号）
- 准则条文用引用块

### 8.2 审计
- 程序描述用动词开头（"获取...""检查...""函证..."）
- 认定与程序对应关系用表格
- 简答题答题模板：结论+依据+结合题干

### 8.3 财管
- 公式独立成行，变量定义清晰
- 计算步骤分点，不省略中间过程
- 指标对比用表格（定义/公式/评价标准/优缺点）

### 8.4 税法
- 税率/征收率用表格汇总
- 税收优惠分类列举
- 计算公式：应纳税额=计税依据×税率，变量定义清晰

### 8.5 经济法
- 法条关键词加粗
- 对比类（如要约vs要约邀请）用表格
- 案例分析：结论+法条依据+案情结合

### 8.6 战略
- 模型/框架用表格或图示（文字版）
- 案例分析：理论+案例对应
- 优缺点对比用表格
