## 五、知识库组织方式（C方案：按章组织 + 顶层双索引）

**目标导向**：知识库最终目标是通过 CPA 税法考试，因此内容分两类——知识拆解（学知识）和考试指导（应对考试），两者组织方式兼顾"按章学习"和"横向速查"。

```
knowledge-base/organized-content/
├── README.md                    # 总入口：课程概述、学习路径、章索引
├── 知识拆解总目录.md             # 按章索引所有知识点（自动生成，当教材用）
├── 考试指导速查手册.md           # 按税种横向汇总：税率表+易错点+口诀+高频考点（自动生成，当应试宝典）
├── 01税法总论/
│   ├── README.md                # 本章概述、子节点链接、重点、学习建议
│   ├── 知识拆解.md               # 核心知识点：定义、分类、原则、税率表、计算方法
│   └── 考试指导.md               # 做题技巧、易错点、记忆口诀、高频考点
├── 02消费税法/
│   ├── README.md
│   ├── 知识拆解.md
│   └── 考试指导.md
...（共15章，结构同上）
```

**两个顶层索引页的定位**：
- 《知识拆解总目录》：学习阶段用，按章顺序串联所有知识点，相当于"自定义教材"
- 《考试指导速查手册》：复习/冲刺阶段用，按税种横向汇总所有应试内容，相当于"应试宝典"，考前直接刷这本

**生成顺序**：先逐章生成知识拆解.md + 考试指导.md，全部完成后自动汇总生成两个顶层索引页。

线 B 题答解析按章归类，作为知识拆解和考试指导的事实依据；用户笔记（若采到）作为补充来源；AI 错题（历史 BUG 产物）不作为来源。
