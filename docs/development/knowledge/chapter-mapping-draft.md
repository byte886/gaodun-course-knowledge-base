## 一、章节映射的核心原则

### 1.1 严格对齐官方课程结构

知识库章节结构必须严格对齐官方课程的讲次结构，确保：
- 章节标题与官方讲次标题完全一致
- 章节顺序与官方讲次顺序完全一致
- 不擅自合并、拆分或重排官方讲次

**为什么**：
- 用户学习时按官方课程顺序进行，知识库对齐官方结构便于对照学习
- AI检索时能精确匹配用户提到的讲次名称
- 避免因擅自合并导致知识点归属模糊

### 1.2 保持讲次完整性

每个官方讲次作为一个独立的知识库章节，即使该讲次包含多个税种，也保持讲次完整性，不按税种拆分。

**为什么**：
- 讲次是课程的最小教学单元，知识点在讲次内有完整的教学逻辑
- 跨税种讲通常有内在的教学衔接（如前一税种的收尾+后一税种的引入）
- 拆分后会破坏教学连贯性，增加检索难度

### 1.3 知识来源按讲次组织

知识库的知识来源（视频转写、讲义OCR、题目/答案/解析、用户笔记）按官方讲次组织，每个讲次对应一组完整的素材。

**为什么**：
- 确保每个章节的知识来源可追溯
- 便于验证知识库内容的完整性
- 支持增量更新（某讲次素材更新时只更新对应章节）

## 二、章节映射方法流程

### 2.1 第一步：获取官方课程结构

从课程平台获取官方课程的完整讲次结构，包括：
- 讲次编号
- 讲次标题
- 讲次顺序
- 讲次类型（全面精讲/强化冲刺/模考等）

**获取方式**：
- 课程大纲API接口
- 课程表页面抓取
- 官方课程目录文档

**验证标准**：
- 讲次数量与官方课程一致
- 讲次标题与官方完全一致（含标点、括号、序号）
- 讲次顺序与官方一致

### 2.2 第二步：建立讲次→章节映射

将每个官方讲次映射为一个知识库章节，映射规则：
- 1讲次 = 1章节
- 章节标题 = 官方讲次标题
- 章节顺序 = 官方讲次顺序

**映射表字段**：
| 字段 | 说明 |
|------|------|
| 讲次编号 | 官方讲次的序号 |
| 讲次标题 | 官方讲次的完整标题 |
| 章节编号 | 知识库章节的序号（与讲次编号一致） |
| 章节标题 | 知识库章节的标题（与讲次标题一致） |
| 讲次类型 | 全面精讲/强化冲刺/模考等 |
| 覆盖税种 | 该讲次涉及的税种（可能多个） |
| 知识来源 | 该讲次对应的视频转写、讲义、题目等素材位置 |

### 2.3 第三步：识别跨税种讲次

识别包含多个税种的讲次，标记为"跨税种讲次"，并记录：
- 涉及的税种列表
- 各税种在讲次中的大致位置（前半/后半/穿插）

**处理原则**：
- 保持讲次完整性，不拆分
- 在章节概述中说明本讲涉及的多个税种
- 知识拆解按税种分段组织，便于检索

### 2.4 第四步：确认映射表

映射表完成后，必须经过确认流程：
1. AI生成映射表初稿
2. 与官方课程结构逐项核对
3. 用户确认映射表
4. 锁定映射表，作为知识库生成的依据

**变更管理**：
- 映射表锁定后，如需变更必须经过用户确认
- 变更时记录变更原因、日期、影响范围
- 变更后同步更新知识库结构

## 三、跨税种讲的处理方法

### 3.1 识别标准

一个讲次满足以下任一条件即为跨税种讲次：
- 讲次标题中包含多个税种名称（如"消费税（3）、城市维护建设税和烟叶税"）
- 讲次内容明显涉及多个税种的核心知识点
- 讲次时长超过单税种常规时长，且内容有明显的税种切换点

### 3.2 内容组织方法

跨税种讲的知识拆解按以下方式组织：

```
# [讲次标题]

## 章节概述
本讲涉及以下税种：
1. [税种A]：[大致位置和内容范围]
2. [税种B]：[大致位置和内容范围]

---

## 一、[税种A]
### 1.1 [知识点1]
...

## 二、[税种B]
### 2.1 [知识点1]
...
```

### 3.3 考试指导组织方法

跨税种讲的考试指导按以下方式组织：

```
# [讲次标题] - 考试指导

## 考情分析
- [税种A]：[考情说明]
- [税种B]：[考情说明]

## 高频考点
### [税种A]
- [考点1]
...

### [税种B]
- [考点1]
...

## 易错点
...
```

## 四、知识库组织方式选择标准

### 4.1 按讲次组织（推荐）

**适用场景**：
- 官方课程结构清晰，讲次边界明确
- 用户按官方课程顺序学习
- 需要与官方课程严格对齐

**优点**：
- 与官方课程1:1对应，便于对照学习
- 知识来源按讲次组织，可追溯
- 支持增量更新

**缺点**：
- 跨税种讲需要在章节内分段组织
- 横向税种汇总需要额外的索引页

### 4.2 按税种组织

**适用场景**：
- 官方课程讲次边界模糊
- 用户需要按税种横向复习
- 税种之间界限清晰，无跨税种讲

**优点**：
- 按税种聚合，便于横向对比和复习
- 税种知识体系完整

**缺点**：
- 与官方课程结构不一致，学习时需要跳转
- 跨税种讲需要拆分，破坏教学连贯性
- 知识来源归属模糊

### 4.3 选择决策树

```
是否需要与官方课程严格对齐？
├─ 是 → 按讲次组织
└─ 否 → 官方课程讲次边界是否清晰？
    ├─ 清晰 → 按讲次组织
    └─ 模糊 → 按税种组织
```

## 五、顶层索引页设计

### 5.1 设计原则

知识库的顶层索引页需要满足以下条件才创建：
1. **不是简单的目录重复**：飞书左侧已有目录树，简单的目录列表无独立价值
2. **有横向汇总价值**：能够跨章节汇总、对比、提炼，提供单章无法提供的视角
3. **有明确的使用场景**：在特定阶段（如复习、冲刺）有不可替代的作用

**不满足以上条件的索引页不创建**，避免冗余。

### 5.2 考试指导速查手册（唯一保留的顶层索引页）

**定位**：复习/冲刺阶段的"应试宝典"，横向汇总所有章节的应试内容，提供单章无法提供的横向对比和速查视角。

**为什么需要**：
- 飞书左侧目录是按讲次顺序的纵向结构，无法提供横向汇总
- 复习阶段需要快速查阅税率表、高频考点、易错点，不需要逐章点击
- 冲刺模考的内容可以汇总进来，形成完整的应试指南
- 跨税种对比（如增值税vs消费税、企业所得税vs个人所得税）只有横向汇总才能实现

**生成时机**：
- 所有章节的考试指导生成完成后
- 冲刺模考内容采集完成后（如有）
- 作为知识库生成的最后一步

**内容来源**：
1. 各章节考试指导中的高频考点、易错点、记忆口诀
2. 各章节知识拆解中的税率表、计算公式
3. 冲刺模考的题目、答案、解析（如有）
4. 跨税种对比和总结（AI基于各章内容提炼）

**内容结构**：
```
# 考试指导速查手册

> 课程：2026 CPA 税法-全面精讲 | 主讲：蔡俊峻老师
> 定位：复习/冲刺阶段应试宝典，横向汇总所有章节应试内容
> 生成时间：YYYY-MM-DD
> 内容来源：各章考试指导 + 知识拆解税率表 + 冲刺模考（如有）
> 重要约束：**不包含具体指定业务的题目或场景要求**，只包含通用知识点和应试指导

---

## 一、考试概况

- 考试形式、题型、分值分布
- 各税种分值占比（按历年真题统计）
- 备考策略和时间分配建议

## 二、税种速查表（按考试重要性排序）

### 2.1 增值税
- 税率表（一般纳税人/小规模纳税人）
- 征收率表
- 高频考点TOP10
- 易错点TOP10
- 记忆口诀
- 计算公式汇总

### 2.2 企业所得税
- 税率表
- 高频考点TOP10
- 易错点TOP10
- 记忆口诀
- 计算公式汇总

...（按考试重要性排序，覆盖所有税种）

## 三、跨税种对比

- 增值税vs消费税：征税范围、税率、计税方法对比
- 企业所得税vs个人所得税：纳税人、税率、扣除项目对比
- 房产税vs城镇土地使用税vs契税：征税范围、税率对比
- 其他易混淆税种对比

## 四、冲刺模考精华（如有）

- 冲刺模考高频考点汇总
- 冲刺模考易错点汇总
- （注：只汇总通用考点和易错点，不包含具体题目或业务场景）

## 五、应试技巧

- 选择题答题技巧
- 计算题答题技巧
- 综合题答题技巧
- 时间分配策略
- 常见陷阱和避坑指南

## 六、考前冲刺清单

- 必背税率表
- 必背计算公式
- 必背高频考点
- 必看易错点
- 最后一周复习计划
```

**生成规则**：
1. 税种按考试重要性排序（增值税、企业所得税、个人所得税为第一梯队）
2. 每个税种的高频考点和易错点从各章考试指导中汇总，按考频排序
3. 税率表和计算公式从各章知识拆解中提取，确保准确
4. 跨税种对比由AI基于各章内容提炼，需要标注"AI总结，建议结合各章详细内容学习"
5. 冲刺模考内容在冲刺模考采集完成后补充，只汇总通用考点和易错点
6. **约束：不包含具体指定业务的题目或场景要求**（如具体计算题、案例分析题、指定章节/税种的具体要求），只包含通用知识点和应试指导
7. 内容控制在合理长度（建议1-2万字），过长则考虑拆分

**质量检查**：
- 税率表与各章知识拆解一致，无错误
- 高频考点覆盖各章考试指导的核心内容
- 易错点有实际题目或解析支撑，不是凭空臆造
- 跨税种对比准确，无误导性内容
- 冲刺模考内容（如有）与原始题目一致

## 六、质量检查清单

章节映射完成后，按以下清单检查：

| 检查项 | 标准 |
|--------|------|
| **讲次数量** | 与官方课程完全一致 |
| **讲次标题** | 与官方完全一致（含标点、括号、序号） |
| **讲次顺序** | 与官方完全一致 |
| **讲次完整性** | 每个讲次作为独立章节，未擅自合并或拆分 |
| **跨税种讲标记** | 跨税种讲已识别并标记 |
| **知识来源映射** | 每个讲次的知识来源已明确映射 |
| **顶层索引页** | 考试指导速查手册已规划（知识拆解总目录不创建，飞书左侧已有目录） |
| **用户确认** | 映射表已经过用户确认并锁定 |

## 七、持续改进

- 每次新课程开始前，按本方法论建立章节映射表
- 定期回顾映射表的实用性，根据用户反馈优化方法论
- 关注官方课程结构的变化，及时更新映射表
- 收集知识库使用反馈，持续优化章节组织方式
