## 节点标题命名规范

### 1. 课程节点（第三级）

**格式**：`【XX考季】VIPCPA系列-XX科目（XX老师）`

**示例**：
- `【26考季】VIPCPA系列-税法（蔡俊峻老师）`
- `【26考季】VIPCPA系列-会计（罗翔老师）`

**规则**：
- 考季用两位数字表示（如26代表2026年）
- 科目名称用标准考试科目名（税法、会计、审计、财务成本管理、公司战略与风险管理、经济法）
- 老师姓名用括号标注

### 2. 章节节点（第四级）

**格式**：严格对齐官方课程讲次标题，不擅自修改、合并或重排。

**示例**：
- `税法全面精讲01-税法总论`
- `税法全面精讲02-消费税法（1）`
- `税法全面精讲04-消费税（3）、城市维护建设税和烟叶税、关税和船舶吨税（1）`

**规则**：
- 章节标题必须与官方课程讲次标题完全一致（含标点、括号、序号、空格）
- 章节顺序必须与官方课程讲次顺序完全一致
- 不擅自合并多个讲次为一个章节
- 不擅自拆分一个讲次为多个章节
- 跨税种讲保持讲次完整性，在章节内按税种分段组织
- 具体课程的讲次映射表作为任务执行数据，不写入本模板文档

### 3. 内容节点（第五级）

**固定名称**：
- `知识拆解` — 核心知识点整理（定义、分类、原则、表格）
- `考试指导` — 考点分析、做题技巧、易错点提醒、记忆口诀

**规则**：
- 每个章节下固定包含这两个子节点
- 名称统一，不随章节变化

## 父节点内容生成原则

### 核心原则

1. **AI自主决定**：遇到新节点时，由AI根据节点层级和子节点情况自主决定是否生成内容，无需询问用户
2. **有子节点必有内容**：如果节点有子节点，必须生成包含子节点链接的目录内容
3. **子节点更新同步父节点**：当子节点内容更新后，父节点的概述、重点内容等也需要同步更新
4. **统一模板**：所有同级节点使用相同的内容模板

## 顶层索引页模板（考试指导速查手册）

**是否需要内容**：是（唯一保留的顶层索引页）

**定位**：复习/冲刺阶段的"应试宝典"，横向汇总所有章节的应试内容，提供单章无法提供的横向对比和速查视角。

**为什么需要**：
- 飞书左侧目录是按讲次顺序的纵向结构，无法提供横向汇总
- 复习阶段需要快速查阅税率表、高频考点、易错点，不需要逐章点击
- 冲刺模考的内容可以汇总进来，形成完整的应试指南
- 跨税种对比只有横向汇总才能实现

**生成时机**：所有章节的考试指导生成完成后，作为知识库生成的最后一步。

**内容来源**：
1. 各章节考试指导中的高频考点、易错点、记忆口诀
2. 各章节知识拆解中的税率表、计算公式
3. 冲刺模考的题目、答案、解析（如有）
4. 跨税种对比和总结（AI基于各章内容提炼）

5. 冲刺模考内容在冲刺模考采集完成后补充，只汇总通用考点和易错点
6. **约束：不包含具体指定业务的题目或场景要求**（如具体计算题、案例分析题、指定章节/税种的具体要求），只包含通用知识点和应试指导
7. 内容控制在合理长度（建议1-2万字），过长则考虑拆分

**质量检查**：
- 税率表与各章知识拆解一致，无错误
- 高频考点覆盖各章考试指导的核心内容
- 易错点有实际题目或解析支撑，不是凭空臆造
- 跨税种对比准确，无误导性内容
- 冲刺模考内容（如有）与原始题目一致

## 父节点内容同步机制

### 触发条件

当子节点内容发生以下变化时，需要同步更新父节点：

1. **新增子节点**：父节点的目录列表需要添加新子节点链接
2. **子节点内容重大更新**：父节点的章节概述、重点内容需要更新
3. **子节点状态变化**：父节点的状态表格需要更新（如"待开始"→"进行中"→"已完成"）

### 同步流程

1. 更新子节点内容
2. 检查父节点是否需要同步更新
3. 更新父节点的目录、概述、重点内容、状态等
4. 更新父节点的"更新记录"
5. 验证父节点内容与子节点一致

    │   ├─ 是 → 必须生成内容（包含子节点目录链接）
    │   └─ 否 → 继续判断
    │
