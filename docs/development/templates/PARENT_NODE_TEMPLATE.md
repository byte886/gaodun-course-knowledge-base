# 飞书父节点目录清单模板

> **文档类型**：Template（模板骨架）
> **更新频率**：模板变更时
> **维护者**：AI自动维护
> **读者**：AI代理

> 本模板专用于**飞书父节点**（模块组父节点、课程根节点）的目录清单页面怎么填。
> 本地与飞书的完整成品骨架（含知识点单篇 4 节）见 [KNOWLEDGE_BASE_TEMPLATE.md](./KNOWLEDGE_BASE_TEMPLATE.md)，组织原则见 [knowledge-base-organization.md](../knowledge/knowledge-base-organization.md)。
> 范式基线 [ADR-012](../../project-management/decisions/ADR-012-三层解耦与按知识点聚合.md)：课程 → 14 模块组（父节点）→ 92 知识点子页面。

## 模板说明

### 适用范围
- **模块组父节点**（如 `02_增值税法`）：下挂本组全部知识点子页面；
- **课程根节点**（如`【26考季】VIPCPA系列-税法（蔡俊峻老师）`）：下挂 14 个模块组 + 课程全局篇。

### 必须包含
1. 信息块：名称、覆盖知识点/题量、来源、适用考季、更新时间；
2. **子节点目录清单**：每个子节点的完整飞书 URL + 一句摘要；
3. 概述与学习目标；
4. 重点内容（3–7 条）；
5. 学习建议。

### 不包含
- 正文知识点内容（父页面只做目录，正文在知识点子页面）；
- 与子页面重复的框架；流程/维护说明（归工程文档，不进飞书）。

## 使用说明

### 创建步骤
1. 先建子页面（知识点篇/模块组），拿到各自 node_token；
2. 复制对应父模板，替换 `{node_token}` 与占位内容；
3. 填写概述、重点、学习建议；
4. 用 lark-cli 写回飞书父节点；
5. 回读验证 URL 全部可达、清单不缺不重。

### 更新步骤
1. 子页面新增/重大更新/状态变化时，同步父节点清单、题量、摘要与重点；
2. 改完回读，确认父清单与实际子节点一致。

### 注意事项
- 清单内一律用**完整飞书 URL**（`https://<域>.feishu.cn/wiki/{node_token}`），不用相对路径；
- 模块组下必须列全本组知识点，课程根下列全 14 组；
- 重点控制 3–7 条；概述简洁；父节点不写正文知识点；
- 任何飞书写操作前先读 lark-wiki / lark-doc 的 SKILL，本地是源头、不在飞书直接编辑正文。
