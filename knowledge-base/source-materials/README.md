# 原始素材目录（source-materials）

> **文档类型**：Reference（参考资料）
> **更新频率**：新增课程或试卷时
> **维护者**：AI自动维护
> **读者**：AI代理（生成知识库时参考）

本目录存放生成知识库的**原始素材**，包括官方解析与用户留言、用户笔记精华等。**题面/标准答案/官方解析的结构化数据不在此**：由 `collect_paper_sources.js` 经只读接口采集到 `data/knowledge-source/papers/`（旧 UI 时代的手抄「做题记录_*.md」已废弃删除，不再产出）。

---

## 目录结构

```
source-materials/
├── <课程名>/
│   ├── 解析与用户留言_<试卷名>.md  # 官方解析和用户留言（永久）
│   └── 用户笔记精华_<课程名>.md    # 高赞用户留言整理（永久）
└── README.md                        # 本文件

题面/标准答案/解析的结构化数据在 data/knowledge-source/papers/<paperId>.json（接口只读采集，.gitignore 不入库）
```

---

## 文件类型与保留策略

| 文件类型 | 命名模式 | 保留策略 | 用途 |
|---------|---------|---------|------|
| **解析与用户留言** | `解析与用户留言_*.md` | ✅ **永久保留** | 官方解析验证知识库准确性，用户留言补充知识点 |
| **用户笔记精华** | `用户笔记精华_*.md` | ✅ **永久保留** | 高赞用户留言，可能包含知识库遗漏的技巧和口诀 |

> 题/答/解析不再以手抄 md 形式存放，统一由接口采集为 `data/knowledge-source/papers/` 下的结构化 JSON。

## 使用场景

### 1. 生成知识库（主要用途）

```
题答解析（data/knowledge-source/papers JSON）+ 解析与用户留言 + 用户笔记精华
    ↓ 整理、提炼、总结
organized-content/（知识拆解、考试指导）
    ↓ 同步
飞书知识库
```

### 2. 追溯来源

当知识库内容有疑问时，追溯到原始素材验证：
- 某个知识点是否正确？→ 查 `解析与用户留言_*.md` 中的官方解析
- 某个技巧从哪来的？→ 查 `用户笔记精华_*.md`

### 3. 补充知识库

发现知识库有遗漏时，从原始素材中补充：
- 用户留言中提到的易错点 → 补充到考试指导
- 官方解析中的详细说明 → 补充到知识拆解

### 4. 验证知识库准确性

用官方解析验证知识库内容：
- 知识库中的答案是否正确？→ 对比官方解析
- 知识库中的解释是否完整？→ 对比官方解析

## 与 organized-content 的关系

| 维度 | source-materials/ | organized-content/ |
|------|-------------------|-------------------|
| 性质 | 原材料 | 成品 |
| 内容 | 原始、未整理 | 整理、提炼、结构化 |
| 用途 | 加工、追溯、验证 | 直接使用、同步飞书 |
| 更新频率 | 采集/整理后新增 | 迭代时更新 |
| 保留策略 | 部分临时、部分永久 | 永久保留 |

## 清理策略与生命周期

- 旧「做题记录_*.md」已废弃（题/答/官方解析由接口 papers JSON 承担），不再产出、也不在此归档。
- 本目录只保留两类素材：`解析与用户留言_*.md`、`用户笔记精华_*.md`。它们的**独有价值是 papers 不包含的「高赞考生留言 / 口诀 / 易错补充」**；其中逐题官方解析与 papers 的 `analysis` 重复，生成时以 papers 为准、不重复读。
- **并非无限期永久保留**：它们是某讲 S2 生成知识成品前的待加工原料（L4）。当该讲三件套生成、并确认留言/口诀已提炼进 organized-content 成品后，原始 md 即完成使命，可按 standards 2.2 清理（结论已入成品、可追溯）；**成品生成前不得提前删**，以免丢失 papers 不覆盖的留言增量。取料规则见 `docs/development/guides/lecture-knowledge-build-sop.md` 步骤2第4点。

---

## 注意事项

1. **不要直接修改原始素材**：原始素材是记录，修改应在 organized-content 中进行
2. **题答走接口采集**：每套卷的题面/标准答案/解析由 `collect_paper_sources.js` 只读采集到 `data/knowledge-source/papers/`，不在本目录生成手抄做题记录；本目录只在确有高价值用户留言/笔记时补充对应整理文件
3. **敏感信息处理**：用户留言中可能包含个人信息，整理到知识库时注意脱敏
4. **冲突处理**：当用户留言与官方解析冲突时，以官方解析为准
