## 章节概述

税收征收管理法是调整税收征收与管理过程中所发生的社会关系的法律规范的总称。本章内容相对独立，分值较低（通常3-5分），主要以客观题形式考查。

本章的重点是税务管理（税务登记、账簿凭证管理、纳税申报）、税款征收（延期缴纳税款、税收滞纳金、税额核定、税收保全措施、税收强制执行措施、税收优先权、税款退还和追征）、法律责任（偷税、骗税、抗税等违法行为的处罚）。

### 重点内容

1. **税收征收管理法概述**：
   - 适用范围（税务机关征收的各种税收）
   - 不适用的税种（关税、船舶吨税、海关代征的增值税和消费税）

2. **税务管理**：
   - 税务登记管理（设立、变更、注销、停业复业）
   - 账簿、凭证管理（设置期限、保存期限）
   - 发票管理
   - 纳税申报管理（申报对象、申报方式、延期申报）

3. **税款征收**：
   - 税款征收的原则和方式
   - 延期缴纳税款制度（特殊困难、最长3个月、省级税务机关批准）
   - 税收滞纳金（万分之五按日加收）
   - 税额核定制度（六种情形）
   - 税收保全措施（冻结存款、扣押查封财产）
   - 税收强制执行措施（扣缴税款、拍卖变卖财产）
   - 税收优先权（税收优先于无担保债权、抵押权质权留置权、罚款没收违法所得）
   - 税款的退还和追征（退还3年、补征3年、追征3-5年、偷税抗税骗税无限期）

4. **税务检查**：
   - 税务检查的形式和方法
   - 税务检查的职责（六项职权）
   - 税务检查的程序

5. **法律责任**：
   - 违反税务管理基本规定行为的处罚
   - 偷税的认定及处罚
   - 虚假申报或不申报的处罚
   - 欠税的处罚
   - 骗取出口退税的处罚
   - 抗税的处罚
   - 不配合税务检查的处罚

6. **纳税担保和纳税信用**：
   - 纳税担保的范围
   - 纳税保证、纳税抵押、纳税质押
   - 纳税信用管理（A、B、M、C、D五级）
   - A级纳税人的激励措施

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是税款征收和法律责任
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 本章内容以记忆为主，需要准确记忆各种期限、金额、比例和处罚标准
- 重点掌握税收保全措施和强制执行措施的区别、税款退还和追征的期限、偷税骗税抗税的处罚标准
- 注意区分税务机关责任和纳税人责任的追征期限和滞纳金处理
