# 知识拆解

> 本文档整理城市维护建设税法和烟叶税法的核心知识点，按考点组织。内容来源于高顿讲义OCR、视频转写和题库38题官方解析。

## 一、城市维护建设税法

### 1.1 城建税的特点

城市维护建设税（简称"城建税"）具有以下特点：

1. **属于附加税**：以纳税人实际缴纳的增值税、消费税税额为计税依据，随"两税"同时征收
2. **根据城镇规模设计地区差别比例税率**：市区7%、县城和镇5%、其他地区1%
3. **征收范围较广**：因为增值税、消费税的征收范围覆盖了大部分经营活动
4. **专款专用**：税款专门用于城市的公用事业和公共设施的维护建设

### 1.2 纳税义务人

城建税的纳税义务人，是指在中华人民共和国境内缴纳增值税、消费税的单位和个人。

**关键规则**：
- 只要缴纳增值税、消费税中的任何一种税，就需要缴纳城建税
- 不缴纳增值税、消费税的单位和个人（如仅缴纳车船税的个人），不是城建税的纳税人
- 外商投资企业、外国企业及外籍个人同样需要缴纳城建税

### 1.3 税率

城建税实行**地区差别比例税率**：

| 纳税人所在地 | 税率 |
|-------------|------|
| **市区** | 7% |
| **县城、镇** | 5% |
| **不在市区、县城或镇** | 1% |

**特殊规定**：
- 由受托方代扣代缴、代收代缴增值税、消费税的单位和个人，其代扣代缴、代收代缴的城建税按**受托方所在地**适用税率执行
- 流动经营等无固定纳税地点的单位和个人，在经营地缴纳增值税、消费税的，其城建税的缴纳按**经营地**适用税率执行
- 开采海洋石油资源的中外合作油（气）田所在地在海上，其城建税适用**1%**的税率

### 1.4 计税依据

城建税的计税依据，是指纳税人**实际缴纳的增值税、消费税税额**。

**计税依据的具体规定**：

| 项目 | 是否计入计税依据 |
|------|----------------|
| 实际缴纳的增值税、消费税 | ✅ 计入 |
| 被税务机关查补的增值税、消费税 | ✅ 计入 |
| 增值税免抵税额 | ✅ 计入（在核准免抵税额的下一个纳税申报期申报缴纳） |
| 增值税、消费税的罚款和滞纳金 | ❌ 不计入 |
| 进口环节缴纳的增值税、消费税 | ❌ 不计入（进口不征） |
| 期末留抵退税退还的增值税税额 | ❌ 允许从计税依据中扣除 |

**关键规则**：
1. **进口不征**：对进口货物或者境外单位和个人向境内销售劳务、服务、无形资产缴纳的增值税、消费税税额，不征收城建税
2. **出口不退**：对出口产品退还增值税、消费税的，不退还已缴纳的城建税
3. **免抵要征**：生产企业出口货物实行免抵退税办法后，经国家税务局正式审核批准的当期免抵的增值税税额应纳入城建税的计征范围
4. **留抵退税可扣**：对实行增值税期末留抵退税的纳税人，允许其从城建税计税依据中扣除退还的增值税税额。纳税人自收到留抵退税额之日起，应当在以后纳税申报期从城建税计税依据中扣除

### 1.5 应纳税额的计算

**应纳税额 = （实际缴纳的增值税税额 + 实际缴纳的消费税税额）× 适用税率**

**计算示例**：
- 位于市区的企业，当月实际缴纳增值税50万元、消费税30万元，被查补增值税15万元并处罚款5万元
- 应缴纳城建税 =（50 + 30 + 15）× 7% = 6.65万元（罚款5万元不计入）

### 1.6 税收优惠

城建税的税收优惠主要包括：

1. **城建税随"两税"的减免而减免**：如果增值税、消费税得到减免，城建税也相应减免
2. **对进口货物或者境外单位和个人向境内销售劳务、服务、无形资产缴纳的增值税、消费税税额，不征收城建税**（进口不征）
3. **对出口产品退还增值税、消费税的，不退还已缴纳的城建税**（出口不退）
4. **对增值税、消费税实行先征后返、先征后退、即征即退办法的，除另有规定外，对随"两税"附征的城建税，一律不予退（返）还**
5. **对国家重大水利工程建设基金免征城建税**
6. **小规模纳税人优惠**：2027年12月31日前，对增值税小规模纳税人可以在50%的税额幅度内减征城建税（由省、自治区、直辖市人民政府确定）

### 1.7 征收管理

**纳税义务发生时间**：城建税的纳税义务发生时间与增值税、消费税的纳税义务发生时间一致，分别与增值税、消费税同时缴纳。

**纳税地点**：
- 一般规定：纳税人缴纳增值税、消费税的地点，就是该纳税人缴纳城建税的地点
- 代扣代缴、代收代缴：代扣代缴、代收代缴增值税、消费税的单位和个人，同时也是城建税的代扣代缴、代收代缴义务人，其城建税的纳税地点在代扣代收地
- 跨省开采的油田：下属生产单位与核算单位不在一个省内的，其生产的原油在油井所在地缴纳增值税，其应纳税款由核算单位按照各油井的产量和规定税率计算汇拨各油井缴纳，城建税由核算单位计算后随同增值税一并汇拨油井所在地，由油井在缴纳增值税的同时一并缴纳
- 管道局输油部分的收入：由取得收入的各管道局于所在地缴纳增值税，其应纳城建税也由取得收入的各管道局于所在地缴纳
- 流动经营：流动经营等无固定纳税地点的单位和个人，应随同增值税、消费税在经营地按适用税率缴纳

**纳税期限**：城建税的纳税期限分别与增值税、消费税的纳税期限一致。

## 二、烟叶税法

### 2.1 纳税义务人

在中华人民共和国境内，依照《中华人民共和国烟草专卖法》的规定**收购烟叶的单位**为烟叶税的纳税人。

**关键规则**：
- 烟叶税的纳税人是**收购烟叶的单位**，不是销售烟叶的个人（烟农）
- 收购烟叶的单位，是指依照《烟草专卖法》的规定有权收购烟叶的烟草公司或者受其委托收购烟叶的单位
- 其他单位和个人不得收购烟叶，因此也不是烟叶税的纳税人

### 2.2 征税范围

烟叶税的征税范围包括：
- **晾晒烟叶**
- **烤烟叶**

### 2.3 税率

烟叶税实行**比例税率**，税率为**20%**。

### 2.4 计税依据

烟叶税的计税依据为纳税人收购烟叶实际支付的价款总额。

**价款总额的确定**：
- 纳税人收购烟叶实际支付的价款总额 = 收购价款 + 价外补贴
- 价外补贴统一按烟叶收购价款的**10%**计算
- 即：价款总额 = 收购价款 ×（1 + 10%）

**关键规则**：
- 价外补贴是指收购烟叶的单位在收购烟叶时，按照收购价款的一定比例支付给烟叶生产销售单位和个人的补贴
- 无论实际支付的价外补贴是多少，税法统一规定按收购价款的10%计入计税依据
- 这是为了简化征管，防止纳税人通过压低收购价款、提高价外补贴的方式避税

### 2.5 应纳税额的计算

**应纳税额 = 收购烟叶实际支付的价款总额 × 税率（20%）**

**计算示例**：
- 某烟草公司收购烟叶，支付收购价款500万元，并按收购价款的10%支付价外补贴
- 价款总额 = 500 ×（1 + 10%）= 550万元
- 应纳烟叶税 = 550 × 20% = 110万元

### 2.6 征收管理

**纳税义务发生时间**：纳税人收购烟叶的当日。

**纳税地点**：纳税人应当向**烟叶收购地**的主管税务机关申报缴纳烟叶税。

**纳税期限**：烟叶税按月计征，纳税人应当于纳税义务发生月终了之日起**15日内**申报并缴纳税款。

## 三、教育费附加和地方教育附加

### 3.1 教育费附加

**征收范围**：凡缴纳增值税、消费税的单位和个人，除按照《国务院关于筹措农村学校办学经费的通知》（国发〔1984〕174号文）的规定，缴纳农村教育事业费附加的单位外，都应当依照规定缴纳教育费附加。

**计征依据**：以各单位和个人实际缴纳的增值税、消费税的税额为计征依据。

**征收率**：教育费附加率为**3%**。

**计算公式**：应纳教育费附加 =（实际缴纳的增值税 + 实际缴纳的消费税）× 3%

**特殊规定**：
- 对海关进口的产品征收的增值税、消费税，不征收教育费附加（进口不征）
- 对出口产品退还增值税、消费税的，不退还已征的教育费附加（出口不退）
- 对由于减免增值税、消费税而发生退税的，可同时退还已征收的教育费附加
- 对增值税、消费税实行先征后返、先征后退、即征即退办法的，除另有规定外，对随"两税"附征的教育费附加，一律不予退（返）还
- 对国家重大水利工程建设基金免征教育费附加
- 小规模纳税人优惠：2027年12月31日前，对增值税小规模纳税人可以在50%的税额幅度内减征教育费附加

### 3.2 地方教育附加

**征收范围**：与教育费附加相同，凡缴纳增值税、消费税的单位和个人都应缴纳。

**计征依据**：以各单位和个人实际缴纳的增值税、消费税的税额为计征依据。

**征收率**：地方教育附加率为**2%**。

**计算公式**：应纳地方教育附加 =（实际缴纳的增值税 + 实际缴纳的消费税）× 2%

**特殊规定**：与教育费附加基本一致，进口不征、出口不退、随"两税"减免而减免。

### 3.3 教育费附加和地方教育附加的减免

**月销售额不超过10万元（季度不超过30万元）的缴纳义务人**：
- 免征教育费附加、地方教育附加
- 该政策适用于增值税一般纳税人和小规模纳税人

**小规模纳税人减半征收**：
- 2027年12月31日前，由省、自治区、直辖市人民政府根据本地区实际情况，以及宏观调控需要确定，对增值税小规模纳税人可以在50%的税额幅度内减征教育费附加和地方教育附加
