## 章节概述

本章包括城市维护建设税法、烟叶税法以及教育费附加和地方教育附加。城建税是一种附加税，以纳税人实际缴纳的增值税、消费税税额为计税依据，随"两税"同时征收。烟叶税是对收购烟叶的单位征收的一种税。教育费附加和地方教育附加是政府性基金，计征依据与城建税相同。

本章内容相对简单，分值较低（通常3-5分），但经常与增值税、消费税结合出现在主观题中，需要重点掌握计税依据的确定和应纳税额的计算。

### 重点内容

1. **城市维护建设税法**：
   - 城建税的特点（附加税、差别比例税率、征收范围广、专款专用）
   - 纳税义务人（缴纳增值税、消费税的单位和个人）
   - 税率（市区7%、县城和镇5%、其他地区1%）
   - 计税依据（实际缴纳的两税、查补的两税、免抵税额；不含罚款滞纳金、进口环节；留抵退税可扣除）
   - 税收优惠（进口不征、出口不退、免抵要征、留抵退税可扣）
   - 征收管理（纳税义务发生时间、纳税地点、纳税期限）

2. **烟叶税法**：
   - 纳税义务人（收购烟叶的单位，不是烟农）
   - 征税范围（晾晒烟叶、烤烟叶）
   - 税率（20%）
   - 计税依据（收购价款+10%价外补贴）
   - 应纳税额计算
   - 征收管理（纳税义务发生时间、纳税地点、纳税期限）

3. **教育费附加和地方教育附加**：
   - 计征依据（与城建税相同）
   - 征收率（教育费附加3%、地方教育附加2%）
   - 减免政策（月销售额10万以下免征、小规模纳税人减半）

- 先阅读「知识拆解」掌握核心知识点，特别是城建税计税依据的确定和烟叶税的计算

- 重点掌握"进口不征、出口不退、免抵要征、留抵退税可扣"这四个关键规则
