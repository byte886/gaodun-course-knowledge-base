## 章节概述

个人所得税是对个人（自然人）取得的各项应税所得征收的一种所得税。个人所得税是CPA税法考试的第二大章节，分值较高（通常15-20分），经常出现在主观题中，特别是综合题和计算题。

本章内容包括纳税人、征税范围、税率、应纳税所得额的规定、税收优惠、境外所得的税额扣除、应纳税额计算中的特殊问题处理、征收管理等。重点是综合所得应纳税所得额的计算（收入额的确定、专项扣除、专项附加扣除）、税收优惠、应纳税额计算中的特殊问题（全年一次性奖金、解除劳动关系补偿、股票期权、个人住房转让、公益捐赠等）。

### 重点内容

1. **纳税义务人与征税范围**：
   - 居民个人与非居民个人的判定（住所和居住时间183天）
   - 居民个人无限纳税义务，非居民个人有限纳税义务
   - 综合所得的范围（工资薪金、劳务报酬、稿酬、特许权使用费）
   - 各项所得的具体范围

2. **税率**：
   - 综合所得税率（3%-45%七级超额累进税率）
   - 经营所得税率（5%-35%五级超额累进税率）
   - 其他所得税率（20%比例税率，个人出租住房减按10%）

3. **应纳税所得额的规定**：
   - 综合所得收入额的确定（工资薪金全额、劳务报酬和特许权使用费减20%、稿酬减20%再减70%）
   - 专项扣除（基本养老保险、基本医疗保险、失业保险、住房公积金）
   - 专项附加扣除（子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护）
   - 非居民个人应纳税所得额
   - 经营所得应纳税所得额
   - 财产租赁所得应纳税所得额
   - 财产转让所得应纳税所得额
   - 利息股息红利所得和偶然所得应纳税所得额

4. **税收优惠**：
   - 免征个人所得税的项目
   - 其他免税项目
   - 减征个人所得税的项目

5. **境外所得的税额扣除**：
   - 抵免限额的计算
   - 超过抵免限额部分的结转（5年）

6. **应纳税额计算中的特殊问题处理**：
   - 全年一次性奖金
   - 解除劳动关系取得的一次性补偿收入
   - 提前退休取得的一次性补贴收入
   - 内部退养取得的一次性收入
   - 企业年金、职业年金
   - 股票期权所得
   - 个人转让上市公司限售股
   - 个人住房转让所得
   - 个人无偿受赠房屋产权
   - 公益捐赠扣除

7. **征收管理**：
   - 纳税申报（综合所得汇算清缴、经营所得汇算清缴）
   - 扣缴义务人
   - 纳税地点

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是综合所得应纳税所得额的计算、税收优惠和应纳税额计算中的特殊问题
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 个人所得税的主观题通常考查综合所得应纳税额的计算，需要熟练掌握收入额的确定、专项扣除、专项附加扣除等
- 重点掌握稿酬所得收入额的计算（减20%再减70%）、专项附加扣除的标准和条件
- 注意区分居民个人和非居民个人应纳税所得额的计算方法
- 注意全年一次性奖金、解除劳动关系补偿、股票期权等特殊问题的计税方法
- 注意公益捐赠扣除的限额（30%）和全额扣除的特定项目
- 注意个人住房转让所得的计税方法和免税条件（5年以上唯一住房）
