## 章节概述

本章包括关税法和船舶吨税法。关税是海关依法对进出境货物、物品征收的一种税，是CPA税法考试的重要章节，经常与增值税、消费税结合出现在主观题中。船舶吨税是对自境外港口进入境内港口的船舶征收的一种税，内容相对简单，分值较低。

本章的重点是关税完税价格的确定、税率的适用、应纳税额的计算、减免规定和征收管理。关税完税价格的确定是本章的难点，需要重点掌握成交价格的调整项目、特殊进口货物的完税价格、出口货物的完税价格。

### 重点内容

1. **关税征税对象与纳税人**：
   - 征税对象（进出境的货物、物品）
   - 纳税人（进口收货人、出口发货人、进境物品收件人）

2. **关税进出口税则**：
   - 进口关税税率（最惠国税率、协定税率、特惠税率、普通税率、暂定税率）
   - 税率适用规则
   - 税率适用日期
   - 税率调整的决定机关

3. **关税完税价格**：
   - 一般进口货物的完税价格（成交价格为基础）
   - 应当计入完税价格的费用
   - 不计入完税价格的费用
   - 保险费无法确定时的计算（货价加运费×3‰）
   - 特殊进口货物的完税价格（境外加工、境外修理、租赁、暂时进境、减免税补税）
   - 出口货物的完税价格

4. **关税应纳税额的计算**：
   - 从价税、从量税、复合税、滑准税

5. **关税减免规定**：
   - 法定减免税
   - 特定减免税
   - 临时减免税

6. **关税征收管理**：
   - 申报时间、缴纳期限、缓纳
   - 强制执行、滞纳金
   - 退还、补征和追征
   - 纳税争议

7. **船舶吨税**：
   - 征税范围与纳税人
   - 税率（优惠税率和普通税率）
   - 应纳税额计算
   - 税收优惠
   - 征收管理

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是关税完税价格的确定和征收管理的时间节点
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 关税经常与增值税、消费税结合出现在主观题中，注意跨章节知识点的结合
- 重点掌握成交价格的调整项目（哪些计入、哪些不计入）、保险费3‰的计算、特殊进口货物的完税价格
- 关税征收管理的时间节点较多（14日、15日、6个月、1年、3年、60日），需要准确记忆
