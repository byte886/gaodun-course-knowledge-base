## 章节概述

本讲是CPA税法的**总纲与概念基础**，介绍税收与税法的基本概念、税法基本原则与适用原则、11项税法要素、我国税收立法级次与现行18税种体系、税收征管范围与中央/地方收入划分、征纳双方权利义务，以及国际税收关系入门。本章不涉及计算，是后续增值税、企业所得税、个人所得税等重点税种的通用语言。

## 重点内容

1. **税法原则**：4项基本原则（法定为核心）与6项适用原则的区分，是历年稳定考点。
2. **税法要素**：征税对象（区别税种标志）、税目（广度）、税率（深度）三者关系，四类税率及代表税种。
3. **税收立法级次**：法律/行政法规/部门规章按制定机关辨认；授权立法为"暂行条例"。
4. **税收收入划分（本章最高频）**：中央固定、地方固定、央地共享三类税种清单，尤其证券交易印花税、海洋石油资源税等特例。
5. **国际税收入门**：重复征税根本原因（管辖权重叠）、类型（法律性为主）、避免方法与税收协定重点（经营所得）。
