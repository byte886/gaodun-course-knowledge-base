## 第一节 税法的概念

### 一、税收与现代国家治理

**税收定义**：政府为了满足社会公共需要，凭借**政治权力**，强制、无偿地取得财政收入的一种形式。

- 国家征税的依据是**政治权力**，而非财产权力、经济权力或管理权力（2022真题、2016真题考点）。
- 税收分配以法律形式进行，区别于基于生产要素的一般分配。

**税收特征（三性）**：

| 特征 | 含义 |
|------|------|
| **强制性** | 凭借政治权力强制征收 |
| **无偿性** | 不需要直接偿还（个体无偿、整体有偿） |
| **固定性** | 预先规定征税标准 |

### 二、税法及特征

**税法含义**：国家制定的用以调整国家与纳税人之间在征纳税方面的权利及义务关系的法律规范的总称。

**税法内容**：各税种法律法规 + 税收征管制度 + 税收管理体制。

**税法特征**：

| 特征 | 含义 | 决定因素 |
|------|------|----------|
| **义务性法规** | 以规定纳税人义务为主 | 由税收的**无偿性、强制性**决定 |
| **综合性法规** | 内容涉及多方面、层次复杂 | 由税收分配关系和税收法律关系的**复杂性**决定 |

> 易错：行政法大多是**授权性**法规，而税法是**义务性**法规。

### 三、税法与其他法律的关系

| 关系 | 类型 | 核心要点 |
|------|------|----------|
| 税法与宪法 | **母子关系** | 宪法是根本大法，税法依据宪法原则制定；宪法第56条规定公民有依法纳税义务 |
| 税法与民法 | **平等关系** | 民法调整平等主体（平等、等价、有偿），税法调整征纳关系（命令与服从）；规范相同时可援引民法，涉及征纳关系时以税法为准 |
| 税法与刑法 | **轻重关系** | 轻者行政处罚、重者刑事责任；刑法用"逃避缴纳税款"取代"偷税"，征管法表述尚未同步 |
| 税法与行政法 | **分支关系** | 税法是行政法分支，但有行政法不具备的两特征：①经济分配性质（纳税人向国家无偿单方面转移）；②义务性法规（行政法多为授权性） |

## 第二节 税法原则

### 一、税法基本原则（4个，"立法"层面的大道理）

| 原则 | 核心内容 | 地位 |
|------|----------|------|
| **税收法定原则** | ①税收要件法定 ②税务合法性 | **核心**基本原则（又称税收法定主义） |
| **税收公平原则** | 按负担能力分配，能力相等税负相同；禁止无正当理由的歧视或特别优惠 | 基本原则 |
| **税收效率原则** | ①经济效率（利于资源配置）②行政效率（节约征管成本） | 基本原则 |
| **实质课税原则** | 依客观事实判定课税要件、按真实负担能力定税负，不能只看外观形式 | 基本原则 |

### 二、税法适用原则（6个，"执法/司法"层面，含"比较"意味）

| 原则 | 核心内容 |
|------|----------|
| **法律优位原则** | 法律＞行政法规＞行政规章；低位阶与高位阶冲突时无效 |
| **法律不溯及既往原则** | 新法实施前的行为不适用新法、沿用旧法（维护稳定性与可预测性） |
| **新法优于旧法原则** | 新旧法对同一事项规定不同时，新法效力优先 |
| **特别法优于普通法原则** | 同一事项特别规定效力高于一般规定；**可打破法律优位**（级别低的特别法可高于级别高的普通法） |
| **实体从旧、程序从新原则** | 实体税法不具溯及力；程序性税法在特定条件下（对纳税人有利时）具一定溯及力 |
| **程序优于实体原则** | 诉讼发生时程序法优于实体法适用（如须先缴税再复议），保证国家课税权及时实现 |

> **基本原则 vs 适用原则**是历年高频多选：法定/公平/效率/实质课税=基本（4个）；其余6个=适用。

## 第三节 税法要素

### 一、税收法律关系

**构成三方面**：主体 + 客体 + 内容。

| 构成 | 内容 | 要点 |
|------|------|------|
| **权利主体** | 征税方 + 纳税方 | ①征税方：各级税务机关、海关；纳税方：法人、自然人、其他组织（属地兼属人）②双方法律地位**平等**，但权利义务**不对等** |
| **权利客体** | 征税对象 | 征纳双方权利义务共同指向的对象（物、所得、行为等） |
| **关系内容** | 权利和义务 | 双方各自享有的权利与承担的义务 |

**产生、变更与消灭**：
- 税法是前提，但**税法本身不能产生**具体税收法律关系；
- 由**税收法律事实**决定，分为税收法律事件与税收法律行为。

### 二、税法要素（11项）

总则、纳税义务人、征税对象、税目、税率、纳税环节、纳税期限、纳税地点、减税免税、罚则、附则。

#### 1. 纳税义务人（纳税主体）

税法规定直接负有纳税义务的单位和个人，两种基本形式：
- **自然人**：包括本国公民、外国人和无国籍人；
- **法人**：包括营利法人、非营利法人和特别法人。

相关概念（不直接负纳税义务）：
- **代扣代缴义务人**：支付收入时代扣代缴（如个人所得税）；
- **代收代缴义务人**：收取收入时代收代缴（如消费税受托加工）。

#### 2. 征税对象（课税对象、征税客体）

- 指税法规定对什么征税；
- **是区别一种税与另一种税的重要标志，是税法最基本的要素**（2016/2023真题）。
- **税目**：对征税对象分类规定的具体征税项目，是对课税对象**质的界定**，体现征税**广度**。
  - **真题补充**：并非所有税种都设税目——**企业所得税不设具体税目**（对全部所得纳税）；增值税、消费税、资源税、印花税、个人所得税等设具体税目。
- **税基（计税依据）**：计算应纳税款的直接数量依据，是对课税对象**量的规定**：
  - 价值形态（从价计征，如增值税）；物理形态（从量计征，如城镇土地使用税）。

#### 3. 税率

计算税额的尺度，衡量税负轻重的重要标志，体现征税**深度**。

| 税率类型 | 含义 | 举例 |
|----------|------|------|
| **比例税率** | 同对象不分数额规定相同比例 | 增值税、城建税、企业所得税、房产税、车辆购置税 |
| **定额税率** | 按计算单位直接规定固定税额 | 城镇土地使用税、车船税、耕地占用税 |
| **超额累进税率** | 按数额分等级、额大率高 | 个人所得税（综合所得七级、经营所得五级超额累进） |
| **超率累进税率** | 按相对率分等级 | 土地增值税（四级超率累进，2024真题） |

比例税率三种具体形式：
- 单一比例税率：车辆购置税；
- 差别比例税率：产品差别（消费税）、行业差别（增值税）、地区差别（城建税）；
- 幅度比例税率：契税。

#### 4. 纳税环节、纳税期限及其他

- **纳税环节**：征税对象在生产到消费流转过程中应缴税的环节。
- **纳税期限三概念**：纳税义务发生时间 → 纳税期限（固定汇总期间，由税务机关核定，不能按期的按次）→ 缴库期限（期限届满后缴入国库的期限）。
- 其他：纳税地点、减税免税、罚则、附则。

## 第四节 税收立法与我国现行税法体系

### 一、税收立法机关与级次

| 分类 | 立法机关 | 形式 | 举例 |
|------|----------|------|------|
| **税收法律** | 全国人大及其常委会正式立法 | ××法 | 企业所得税法、个人所得税法、车船税法、环保税法、烟叶税法、船舶吨税法、车辆购置税法、耕地占用税法、资源税法、契税法、城建税法、印花税法、增值税法、关税法等 |
| **授权立法** | 全国人大及其常委会**授权国务院**立法 | ××暂行条例（具法律性质地位） | 《消费税暂行条例》（消费税尚未立法） |
| **税收行政法规** | 国务院 | ××条例、××实施条例 | 《企业所得税法实施条例》《税收征收管理法实施细则》 |
| **税收部门规章** | 财政部、税务总局、海关总署 | ××细则/办法 | 《消费税暂行条例实施细则》 |

> **真题补充（易错）**：判断级次看制定机关——全国人大及其常委会=法律；国务院=行政法规；财政部/税务总局/海关总署=部门规章。**消费税、土地增值税、房产税、城镇土地使用税**等目前仍以"暂行条例"形式存在、尚未上升为法律。

### 二、税收立法程序

三阶段：**提议**（财政部/税务总局调研起草上报国务院）→ **审议**（法律由全国人大或其常委会、行政法规由国务院）→ **通过和公布**（法律以国家主席令、行政法规以国务院总理令发布）。

### 三、现行税法体系

#### 1. 税收实体法（18个税种，分5类）

| 类别 | 税种 |
|------|------|
| 商品和劳务税类（流转税/间接税） | 增值税、消费税、关税 |
| 所得税类（直接税） | 企业所得税、个人所得税 |
| 财产和行为税类 | 房产税、契税、车船税、印花税 |
| 资源税类 | 资源税、环境保护税、城镇土地使用税、土地增值税 |
| 特定目的税类 | 城市维护建设税、烟叶税、船舶吨税、耕地占用税、车辆购置税 |

我国税制以**间接税和直接税为双主体**结构。

#### 2. 税收程序法

- 税务机关征收的税种：依《税收征收管理法》（典型程序法，2022真题）；
- 海关征收的税种：依《海关法》及《进出口关税条例》。

## 第五节 税收执法

### 一、税收征收管理范围划分

| 征收机关 | 征收税种 |
|----------|----------|
| **海关** | 与进口环节有关的：进口增值税、进口消费税、关税、船舶吨税 |
| **税务机关** | 除海关征收以外的其余税种（绝大部分工商税收） |

### 二、税收执法权的构成（真题补充）

税收执法权是税务机关依法征税和进行税收管理的权力，具体包括：**税款征收权、税务稽查权、税务检查权、税务行政复议裁决权、其他税务管理权**。

### 三、税收收入划分

#### 1. 中央政府固定收入

消费税（含进口环节海关代征）、车辆购置税、关税、海关代征的进口环节增值税、**船舶吨税**、证券交易印花税。

#### 2. 中央与地方共享收入

| 税种 | 划分 |
|------|------|
| **增值税**（不含进口海关代征） | 中央50%、地方50% |
| **企业所得税** | 中国铁路总公司、各银行总行、海洋石油企业归中央；其余中央60%、地方40% |
| **个人所得税** | 储蓄存款利息个税归中央；其余中央60%、地方40% |
| **资源税** | **海洋石油企业缴纳部分归中央，其余归地方**（2023真题） |
| **城建税** | 中国铁路总公司、各银行总行、各保险总公司集中缴纳部分归中央，其余归地方 |
| **印花税** | **证券交易印花税100%归中央**，其余印花税归地方 |

#### 3. 地方政府固定收入

城镇土地使用税、耕地占用税、土地增值税、房产税、车船税、契税、烟叶税、环境保护税。

> 记忆规律：地方固定收入多与**不动产/土地**相关（城镇土地使用税、耕地占用税、土地增值税、房产税、契税）+ 车船税、烟叶税、环保税。

## 第六节 税务机关和纳税人的权利与义务

### 一、税务机关、税务人员

- **权利（2项）**：①负责税收征收管理；②依法执行职务，任何单位和个人不得阻挠。
- **义务（5项）**：宣传税法/无偿咨询；队伍建设；秉公执法文明服务、尊重保护纳税人权利；不索贿受贿、不玩忽职守不征少征、不滥用职权多征；为检举人保密并奖励。

### 二、纳税人、扣缴义务人

**权利**：
1. 了解国家税收法律、行政法规及纳税程序的知情权；
2. 依法申请减税、免税、退税；
3. 陈述权、申辩权，依法申请行政复议、提起行政诉讼、请求国家赔偿；
4. **保密权（真题补充）**：要求税务机关对其**商业秘密和个人隐私**保密（税收违法行为信息不属于保密范围）。

**义务（3项）**：依法纳税/代扣代收代缴；如实提供相关信息；接受税务检查。

### 三、涉税专业服务机构涉税业务内容

纳税申报代理、一般税务咨询、专业税务顾问、**税收策划**（提供符合法规的纳税计划/方案，2020真题）、涉税鉴证、纳税情况审查、其他税务事项代理（代理建账记账、发票领用、减免退税申请等）、其他涉税服务。

## 第七节 国际税收关系

### 一、国际重复课税

#### 1. 产生根本原因

**税收管辖权的相互重叠**（2010真题）。三种重叠情形：
1. 居民（公民）管辖权与地域管辖权重叠；
2. 居民（公民）管辖权之间重叠；
3. 地域管辖权之间重叠。

#### 2. 税收管辖权类型

| 管辖权 | 含义 |
|--------|------|
| 公民管辖权 | 依国籍，对本国公民全球所得征税 |
| 居民管辖权 | 对本国居民全球所得征税 |
| 地域管辖权（来源地） | 对来源于本国境内的所得征税 |

#### 3. 国际重复征税类型

| 类型 | 含义 |
|------|------|
| **法律性** | 不同国家对**同一纳税人**因征税原则不同导致管辖权重叠（**国际税收一般所指**） |
| **经济性** | 不同国家对**不同纳税人**的同一税源重复征税 |
| **税制性** | 复合税制下一国对同一对象征收几种税 |

避免重复征税主要采用**免税法和抵免法**，具体方法与条件须在税收协定中明确。

### 二、国际税收协定

1. 国际税收协定**优于**国内税法；与国内税法具同等法律效力，冲突时按"新法优于旧法""特别法优于普通法"协调。
2. 国际认可所得四大类：**经营所得、劳务所得、投资所得、财产所得**，其中**经营所得（营业利润）是协定处理重复征税问题的重点项目**（2024真题）。

### 三、国际避税与反避税

- **国际避税**：纳税人利用两国以上税法和协定的漏洞、特例、缺陷，规避或减轻全球总纳税义务（表现含人员流动、资金/货物/劳务转移等）。
- **国际反避税与协作**：
  1. **BEPS（税基侵蚀和利润转移行动计划）**：G20背书、委托OECD推进，应对跨国企业利用规则不足与税制差异造成双重不征税、侵蚀各国税基；
  2. 《多边税收征管互助公约》；
  3. 《金融账户涉税信息自动交换多边主管当局间协议》。
