## 章节概述

增值税法是CPA税法考试的**最重要章节**，分值占比最高（通常20-30分），也是主观题的必考章节。本章主要介绍增值税的纳税义务人、征税范围、税率与征收率、一般计税方法（销项税额、进项税额、应纳税额）、简易计税方法、进口环节增值税、出口货物和跨境销售增值税政策、税收优惠、征收管理等内容。

增值税法内容多、考点细、计算复杂，需要重点掌握一般计税方法下销项税额和进项税额的计算，以及出口"免、抵、退"税的计算。

### 重点内容

1. **增值税应税交易的范围**：境内应税交易判定、视同应税交易、不征收增值税项目、易混淆服务归类
2. **增值税税率与征收率**：13%/9%/6%三档税率适用范围、3%/5%征收率及减按征收的特殊规定
3. **一般计税方法——销项税额**：特殊销售方式（折扣销售、以旧换新、还本销售）、房地产开发企业差额计税、视同销售销售额确定
4. **一般计税方法——进项税额**：农产品扣除率、国内旅客运输服务抵扣、不得抵扣进项税额的范围、进项税额转出（固定资产净值、兼营分摊）
5. **一般计税方法——应纳税额**：应纳税额计算、留抵税额、留抵退税
6. **简易计税方法**：一般纳税人可选择简易计税的项目、销售使用过的固定资产的税务处理
7. **进口环节增值税**：组成计税价格计算、关税计税价格确定（CIF、保险费3‰）、跨境电商零售进口
8. **出口货物和跨境销售增值税政策**：生产企业"免、抵、退"税四步计算、出口免税不退税、零税率应税服务、境外旅客购物离境退税
9. **增值税税收优惠**：小规模纳税人免税政策、农业生产者销售自产农产品、供热企业向居民供热
10. **增值税征收管理**：纳税义务发生时间、纳税期限、跨县（市、区）建筑服务预缴

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是税率表、进项税额抵扣规则、出口退税计算公式
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 通过做题验证掌握程度，重点练习一般计税方法的综合计算题和出口"免、抵、退"税计算题
- 增值税法与其他章节（消费税、企业所得税、关税）联系紧密，注意跨章节知识点的结合
