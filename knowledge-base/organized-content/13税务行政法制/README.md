## 章节概述

税务行政法制是规范税务机关和税务行政相对人在税务行政活动中的权利义务关系的法律规范的总称。本章内容相对独立，分值较低（通常2-3分），主要以客观题形式考查。

本章包括税务行政处罚、税务行政复议和税务行政诉讼三部分内容。重点是税务行政处罚的设定和种类、听证程序、税务行政复议的受案范围和管辖、复议前置、税务行政诉讼的原则和判决种类。

### 重点内容

1. **税务行政处罚**：
   - 税务行政处罚的原则
   - 税务行政处罚的设定和种类
   - 税务行政处罚的主体与管辖
   - 税务行政处罚的简易程序
   - 税务行政处罚的一般程序（听证程序）
   - 税务行政处罚的执行

2. **税务行政复议**：
   - 税务行政复议的概念和特点
   - 税务行政复议的受案范围
   - 税务行政复议的管辖
   - 税务行政复议的申请（复议前置）
   - 税务行政复议的受理
   - 税务行政复议的审查和决定
   - 行政复议中止和终止
   - 税务行政复议的和解与调解

3. **税务行政诉讼**：
   - 税务行政诉讼的概念和特点
   - 税务行政诉讼的原则
   - 税务行政诉讼的管辖
   - 税务行政诉讼的受案范围
   - 税务行政诉讼的起诉和受理
   - 税务行政诉讼的审理和判决

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是税务行政处罚的听证程序、税务行政复议的复议前置和管辖、税务行政诉讼的原则
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 本章内容以记忆为主，需要准确记忆各种期限、金额、比例和程序
- 重点掌握税务行政处罚听证的范围和期限、税务行政复议的申请期限和决定期限、税务行政诉讼的起诉期限和审理期限
- 注意区分税务行政复议和税务行政诉讼的衔接关系（复议前置和选择复议）
