## 章节概述

企业所得税是对我国境内的企业和其他取得收入的组织的生产经营所得和其他所得征收的一种所得税。企业所得税是CPA税法考试的最重要章节，分值最高（通常20-30分），经常出现在主观题中，特别是综合题。

本章内容非常多，包括纳税人、征税对象、税率、收入总额、不征税收入和免税收入、扣除项目、不得扣除项目与亏损弥补、资产的税务处理、资产损失、重组业务、税收优惠、应纳税额的计算、征收管理等。重点是扣除项目的标准、不得扣除项目、资产的税务处理、税收优惠和应纳税额的计算。

### 重点内容

1. **纳税义务人、征税对象与税率**：
   - 居民企业与非居民企业的判定
   - 居民企业无限纳税义务（境内外所得），非居民企业有限纳税义务（境内所得）
   - 所得来源地的确定
   - 税率（25%基本税率、10%预提所得税、15%优惠税率、20%小型微利企业）

2. **收入总额**：
   - 一般收入的确认时间
   - 特殊收入的确认（分期收款、持续超过12个月、产品分成、视同销售）
   - 处置资产收入的确认（内部处置不视同销售，移送他人视同销售）
   - 相关收入实现的确认

3. **不征税收入和免税收入**：
   - 不征税收入（财政拨款、行政事业性收费政府性基金、专项用途财政性资金）
   - 专项用途财政性资金的三个条件
   - 免税收入（国债利息、居民企业之间股息红利、非居民企业从居民企业取得股息红利、非营利组织收入）

4. **扣除项目**：
   - 工资薪金支出
   - 职工福利费（14%）、工会经费（2%）、职工教育经费（8%，超过部分结转）
   - 社会保险费
   - 利息费用（金融企业同期同类贷款利率、关联企业资本弱化规则）
   - 业务招待费（发生额60%与销售营业收入5‰孰低）
   - 广告费和业务宣传费（一般15%，化妆品医药饮料30%，超过部分结转）
   - 公益性捐赠（年度利润总额12%，超过部分结转3年）
   - 手续费及佣金

5. **不得扣除项目与亏损弥补**：
   - 不得扣除项目
   - 亏损弥补（一般5年，高新技术企业和科技型中小企业10年）

6. **资产的税务处理**：
   - 固定资产的计税基础、折旧范围、折旧方法、最低年限、加速折旧、一次性扣除
   - 生物资产的税务处理
   - 无形资产的税务处理
   - 长期待摊费用的税务处理
   - 存货的税务处理
   - 投资资产的税务处理

7. **重组业务的税务处理**：
   - 重组的类型
   - 一般性税务处理
   - 特殊性税务处理的五个条件
   - 特殊性税务处理的规定

8. **税收优惠**：
   - 免征与减征优惠（农林牧渔、公共基础设施、环保节能节水、技术转让）
   - 高新技术企业优惠（15%）
   - 小型微利企业优惠（实际税负5%）
   - 加计扣除优惠（研发费用100%、安置残疾人员100%）
   - 创投企业优惠（投资额70%抵扣）
   - 加速折旧优惠
   - 减计收入优惠（90%）
   - 税额抵免优惠（专用设备投资额10%）
   - 软件产业和集成电路产业优惠

9. **应纳税额的计算**：
   - 居民企业应纳税额的计算（直接法和间接法）
   - 境外所得抵扣税额的计算
   - 非居民企业应纳税额的计算（预提所得税）

10. **征收管理**：
    - 纳税地点
    - 纳税期限
    - 纳税申报

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是扣除项目的标准、不得扣除项目、资产的税务处理和税收优惠
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 企业所得税的主观题通常考查应纳税所得额的计算，需要熟练掌握收入的确认、扣除项目的标准、不得扣除项目、税收优惠等
- 重点掌握业务招待费、广告费和业务宣传费、公益性捐赠、职工福利费、工会经费、职工教育经费等扣除限额的计算
- 注意区分不征税收入和免税收入，以及不征税收入用于支出形成的费用和资产折旧摊销不得扣除
- 注意固定资产折旧最低年限、加速折旧和一次性扣除政策
- 注意特殊性税务处理的五个条件和非股权支付对应的资产转让所得或损失的计算
- 注意境外所得抵免限额的计算和超过抵免限额部分的结转
