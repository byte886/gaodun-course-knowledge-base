## 章节概述

强化冲刺阶段是CPA税法考试备考的最后阶段，主要目的是综合复习各章节重点和难点，掌握应试技巧，提高答题速度和准确率。本章内容涵盖7个专题：增值税法、企业所得税法、消费税法、个人所得税法、土地增值税法、国际税收、其他小税种。

本章的重点是各税种的应纳税额计算、税收优惠政策、易错点和高频考点。通过强化冲刺阶段的复习，考生应该能够熟练掌握各税种的计算方法和应试技巧，为考试做好充分准备。

### 重点内容

1. **增值税法（专题一）**：
   - 增值税征税范围（一般规定、视同销售、混合销售、兼营）
   - 增值税税率和征收率
   - 增值税应纳税额计算
   - 增值税进项税额抵扣
   - 增值税税收优惠

2. **企业所得税法（专题二）**：
   - 企业所得税纳税人
   - 企业所得税税率
   - 企业所得税应纳税所得额
   - 企业所得税税收优惠
   - 企业所得税应纳税额计算

3. **消费税法（专题三）**：
   - 消费税征税范围
   - 消费税税率
   - 消费税应纳税额计算
   - 自产自用、委托加工、进口应税消费品的组成计税价格
   - 消费税已纳税额扣除

4. **个人所得税法（专题四）**：
   - 个人所得税纳税人
   - 个人所得税征税项目
   - 个人所得税税率
   - 个人所得税应纳税所得额
   - 专项附加扣除
   - 个人所得税税收优惠

5. **土地增值税法（专题五）**：
   - 土地增值税征税范围
   - 土地增值税税率
   - 土地增值税应纳税额计算
   - 土地增值税税收优惠

6. **国际税收（专题六）**：
   - 境外所得税额抵免
   - 国际反避税

7. **其他小税种（专题七）**：
   - 城市维护建设税法
   - 烟叶税法
   - 关税法
   - 船舶吨税法
   - 资源税法
   - 环境保护税法
   - 城镇土地使用税法
   - 耕地占用税法
   - 房产税法
   - 契税法
   - 车辆购置税法
   - 车船税法
   - 印花税法

### 学习建议

- 先阅读「知识拆解」掌握各税种的核心知识点和计算方法
- 再阅读「考试指导」了解应试技巧、高频考点和易错点
- 强化冲刺阶段应该以做题为主，通过做题巩固知识点，提高答题速度和准确率
- 重点掌握增值税法、企业所得税法、个人所得税法的综合计算题
- 注意各税种之间的联系和区别，特别是增值税和消费税、企业所得税和个人所得税
- 合理安排答题时间，先做会做的题目，不会的题目标记后回头再做
- 注意答题规范，分步计算，写出计算公式和过程
