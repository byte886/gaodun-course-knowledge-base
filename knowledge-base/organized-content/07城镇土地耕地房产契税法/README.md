## 章节概述

本章包括四个小税种：城镇土地使用税法、耕地占用税法、房产税法和契税法。这四个税种都与土地和房屋相关，内容相对独立，分值较低（通常8-12分），但考点细致，需要准确记忆纳税人、征税范围、计税依据、税收优惠和征收管理的特殊规定。

城镇土地使用税和房产税是按年征收的财产税，耕地占用税是一次性征收的行为税，契税是在权属转移时征收的财产税。四个税种的纳税义务发生时间、纳税地点和纳税期限各有特点，需要对比记忆。

### 重点内容

1. **城镇土地使用税法**：
   - 纳税人（拥有土地使用权的单位和个人；土地使用权未确定的由实际使用人纳税；共有的由各方分别纳税）
   - 征税范围（城市、县城、建制镇、工矿区，不包括农村）
   - 计税依据（实际占用的土地面积；地下建筑按垂直投影面积，暂按50%征收）
   - 税收优惠（法定免税项目、企业办学校医院托儿所幼儿园自用土地免税、免税单位无偿使用纳税单位土地免税）
   - 纳税义务发生时间（次月起、满1年起等特殊规定）

2. **耕地占用税法**：
   - 纳税人（占用耕地建设建筑物构筑物或从事非农业建设的单位和个人）
   - 征税范围（耕地，包括园地、林地、草地等农用地）
   - 税率（定额税率，人均耕地越少税率越高；占用基本农田加按150%征收）
   - 计税依据（实际占用耕地面积，一次性征收）
   - 税收优惠（军事设施、学校、幼儿园、社会福利机构、医疗机构免税；农村居民新建自用住宅减半；特定人群免征）
   - 征收管理（纳税义务发生时间、30日内申报、临时占用1年内复垦全额退还）

3. **房产税法**：
   - 纳税人（产权所有人；产权出典的承典人；不在所在地或权属未定的代管人或使用人；无租使用的使用人代缴）
   - 征税范围（城市、县城、建制镇、工矿区，不包括农村；房地产开发企业建造的商品房出售前不征）
   - 税率（从价1.2%，从租12%，个人出租住房4%）
   - 计税依据（从价：房产原值减除10%-30%后的余值；从租：租金收入）
   - 特殊规定（投资联营、融资租赁、地下建筑、免收租金）
   - 税收优惠（法定免税项目、企业办学校医院托儿所幼儿园自用、大修停用半年以上、基建工地临时性房屋）
   - 纳税义务发生时间

4. **契税法**：
   - 纳税人（承受土地、房屋权属的单位和个人）
   - 征税范围（国有土地使用权出让、土地使用权转让、房屋买卖、房屋赠与、房屋交换；视同发生应税行为）
   - 税率（3%-5%幅度比例税率）
   - 计税依据（成交价格、差额、核定价格）
   - 税收优惠（法定免税项目、个人购买家庭唯一住房和第二套改善性住房优惠）
   - 征收管理（纳税义务发生时间、纳税地点）

### 学习建议

- 先阅读「知识拆解」掌握四个税种的核心知识点，特别是纳税人、计税依据和税收优惠
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 四个税种可以对比记忆：城镇土地使用税和房产税是按年征收，耕地占用税和契税是一次性征收
- 城镇土地使用税和房产税的纳税义务发生时间多为"次月起"，耕地占用税是"收到通知当日起30日内"，契税是"签订合同当日起，登记前申报"
- 四个税种的纳税地点都是土地/房屋所在地，不是机构所在地
- 四个税种都由税务机关征收，不是海关
- 小规模纳税人优惠（六税两费减半）适用于城镇土地使用税、房产税、耕地占用税、契税
