## 章节概述

土地增值税是对有偿转让国有土地使用权及地上建筑物和其他附着物产权，取得增值收入的单位和个人征收的一种税。土地增值税是CPA税法考试的重要章节，分值较高（通常8-12分），经常出现在主观题中，特别是房地产开发企业土地增值税清算的计算题。

本章的重点是征税范围的判定、扣除项目的确定（特别是房地产开发费用的两种扣除方法、加计20%扣除）、应纳税额的计算（四级超率累进税率的运用）、房地产开发企业土地增值税清算（清算条件、清算时收入和扣除项目的确定）。

### 重点内容

1. **纳税义务人与征税范围**：
   - 纳税人（转让国有土地使用权、地上建筑物及其附着物并取得收入的单位和个人，即转让方）
   - 征税范围（三个标准：国有土地、产权转让、取得收入）
   - 具体事项征税范围判定（继承、赠与、出租、抵押、交换、投资联营、合作建房、代建房、重新评估等）

2. **税率**：
   - 四级超率累进税率（30%、40%、50%、60%）
   - 速算扣除系数（0、5%、15%、35%）

3. **应税收入与扣除项目**：
   - 应税收入（不含增值税收入）
   - 扣除项目（取得土地使用权支付金额、房地产开发成本、房地产开发费用、与转让房地产有关的税金、加计20%扣除）
   - 房地产开发费用的两种扣除方法（利息能分摊提供证明的5%以内，不能的10%以内）
   - 旧房及建筑物的扣除（评估价格、购房发票加计5%）

4. **应纳税额的计算**：
   - 计算步骤（扣除项目金额、增值额、增值率、税率、应纳税额）
   - 房地产开发企业土地增值税清算（清算单位、清算条件、清算时收入和扣除项目的确定、清算后再转让的处理）

5. **税收优惠**：
   - 建造普通标准住宅的税收优惠（增值率不超过20%免征）
   - 国家征用收回的房地产免税
   - 个人转让住房暂免
   - 企业改制重组的税收优惠

6. **征收管理**：
   - 纳税地点（房地产所在地）
   - 纳税申报（合同签订之日起7日内）
   - 清算申报（满足条件或收到通知之日起90日内）

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是扣除项目的确定和应纳税额的计算
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 土地增值税的主观题通常考查房地产开发企业土地增值税清算，需要熟练掌握扣除项目的计算和四级超率累进税率的运用
- 重点掌握房地产开发费用的两种扣除方法、加计20%扣除的适用条件、与转让房地产有关的税金的范围
- 注意区分房地产开发企业和非房地产开发企业的扣除项目差异（加计20%扣除、印花税扣除）
- 注意区分新建房和旧房的扣除项目差异（评估价格、购房发票加计5%）
- 征税范围的判定是客观题的高频考点，需要准确记忆各种具体事项是否征税
