## 章节概述

国际税收税务管理实务是规范国家之间税收分配关系和税收征管合作的法律制度的总称。本章内容相对独立，分值中等（通常5-8分），主要以客观题和计算分析题形式考查。

本章包括国际税收协定、国际税收征管合作、境外所得税收管理和国际反避税四部分内容。重点是国际税收协定中的常设机构判定和投资所得限制税率、境外所得税额抵免的计算、转让定价方法、受控外国企业和资本弱化规则。

### 重点内容

1. **国际税收协定**：
   - 税收居民的判定（加比规则）
   - 常设机构的判定（固定营业场所、建筑工地183天、代理人）
   - 营业利润的征税原则
   - 投资所得（股息、利息、特许权使用费）的限制税率
   - 财产所得的征税规则
   - 劳务所得的征税规则
   - 消除双重征税的方法

2. **国际税收征管合作**：
   - 情报交换的种类
   - 税收情报的密级和保密期限
   - 税收情报的使用限制
   - FATCA的主要内容
   - CRS的主要内容和中国实施时间

3. **境外所得税收管理**：
   - 境外所得税额抵免的计算（抵免限额）
   - 超过抵免限额部分的处理
   - 间接抵免的条件
   - 个人境外所得税额抵免

4. **国际反避税**：
   - 关联申报和同期资料管理
   - 转让定价方法
   - 预约定价安排
   - 成本分摊协议
   - 受控外国企业
   - 资本弱化
   - 一般反避税

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是常设机构判定、境外所得税额抵免计算、转让定价方法
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 本章内容需要记忆和计算并重，需要准确记忆各种比例、期限和标准
- 重点掌握境外所得税额抵免的计算（分国计算、抵免限额、5年结转）
- 注意区分直接抵免和间接抵免的适用条件
- 国际反避税部分需要掌握受控外国企业、资本弱化、一般反避税的判定标准和税务处理
