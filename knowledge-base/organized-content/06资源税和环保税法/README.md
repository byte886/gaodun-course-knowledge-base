## 章节概述

本章包括资源税法和环境保护税法。资源税是对在我国领域和管辖海域开发应税资源的单位和个人征收的一种税。环境保护税是对直接向环境排放应税污染物的企业事业单位和其他生产经营者征收的一种税。

本章内容相对独立，分值较低（通常5-8分），但考点细致，需要准确记忆计税依据、税收优惠和征收管理的特殊规定。资源税的重点是计税依据的确定（原矿与选矿的区分、外购应税产品的扣减）和税收优惠。环境保护税的重点是计税依据（污染当量数的计算、前三项/前五项的征税规则）和税收优惠。

### 重点内容

1. **资源税法**：
   - 纳税义务人（开发应税资源的单位和个人，进口不征）
   - 征税范围（能源矿产、金属矿产、非金属矿产、水气矿产、盐五大类）
   - 税率（从价计征为主，从量计征为辅）
   - 计税依据（销售额、销售数量；原矿与选矿的区分；外购应税产品的扣减）
   - 应纳税额计算
   - 税收优惠（免征：加热原油天然气、安全抽采煤成气；减征：低丰度20%、高含硫深水30%、稠油高凝40%、衰竭期30%）
   - 征收管理（纳税义务发生时间、纳税地点、纳税期限）

2. **环境保护税法**：
   - 纳税义务人（直接排放应税污染物的企事业单位和其他生产经营者，家庭和个人不是）
   - 征税范围（大气污染物、水污染物、固体废物、噪声四类）
   - 税率（定额税率）
   - 计税依据（污染当量数、排放量、超标分贝数；大气前三项、水第一类前五项其他类前三项）
   - 应纳税额计算
   - 税收优惠（免征：农业生产、流动污染源、集中处理达标、综合利用达标；减征：低于标准30%减按75%、低于50%减按50%）
   - 征收管理（纳税义务发生时间、纳税地点、纳税期限）

### 学习建议

- 先阅读「知识拆解」掌握核心知识点，特别是资源税的计税依据和环保税的污染当量数计算
- 再阅读「考试指导」了解考点、易错点和记忆口诀
- 资源税注意区分原矿与选矿的征税对象、外购应税产品的扣减计算
- 环保税注意大气污染物前三项、水污染物第一类前五项其他类前三项的征税规则
- 两税的税收优惠都需要准确记忆，特别是减征比例和适用条件
- 两税都由税务机关征收，纳税地点都是开采地/生产地/排放地，不是机构所在地
