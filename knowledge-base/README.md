# 知识库目录（knowledge-base）

> **文档类型**：Reference（参考资料）
> **更新频率**：新增课程或知识库结构变更时
> **维护者**：AI自动维护
> **读者**：AI代理+人类

本目录存放**知识库相关内容**，包括整理后的知识内容和原始素材。

---

## 目录结构

```
knowledge-base/
├── organized-content/     # 整理后的知识内容（成品，同步飞书）
│   ├── README.md           # 本目录说明
│   ├── 做题思路解析.md     # 通用做题方法论
│   └── <章节名>/           # 各章节知识
│       ├── README.md       # 章节概览
│       ├── 知识拆解.md     # 核心知识点
│       └── 考试指导.md     # 考点、易错点、记忆口诀
├── source-materials/      # 原始素材（原材料，用于生成知识库）
│   ├── README.md           # 本目录说明
│   └── <课程名>/           # 各课程的原始素材（题答走 data/knowledge-source 接口采集）
│       ├── 解析与用户留言_*.md # 官方解析和用户留言（永久）
│       └── 用户笔记精华_*.md   # 高赞用户留言（永久）
├── lecture-resource-map.json # 讲次→课件/OCR/转写取料路由（ADR-011，入库版本化；scripts/verify_lecture_map.py 校验/--rebuild重建）
└── README.md               # 本文件
```

---

## 两个子目录的区别

| 维度 | organized-content/ | source-materials/ |
|------|-------------------|-------------------|
| **性质** | 成品 | 原材料 |
| **内容** | 整理、提炼、结构化 | 原始、未整理 |
| **用途** | 直接使用、同步飞书 | 加工、追溯、验证 |
| **生成方式** | AI整理提炼 | 做题时自动记录 |
| **保留策略** | 永久保留 | 部分临时、部分永久 |
| **同步飞书** | ✅ 是 | ❌ 否 |

---

## 工作流程

```
1. 做题采集
   ↓
source-materials/（原始素材）
   ↓ 2. AI整理、提炼、总结
organized-content/（整理后的知识内容）
   ↓ 3. 验证（做题验证正确率）
   ↓ 4. 同步
飞书知识库（最终用户使用）
```

## 什么时候用哪个目录？

### 用 organized-content/ 的场景

- ✅ 同步到飞书知识库
- ✅ 做题时查询答案
- ✅ 用户学习时阅读
- ✅ 知识库迭代更新
- ✅ 检查知识库质量

### 用 source-materials/ 的场景

- ✅ 生成 organized-content 时参考
- ✅ 追溯知识库内容的来源
- ✅ 验证知识库内容的准确性
- ✅ 发现知识库遗漏时补充
- ✅ 复盘做题过程

## 保留策略

### organized-content/

- **成品永久保留**，作为飞书知识库的源头和备份（验证/同步默认不单独成文，结论并入任务报告）

### source-materials/

只保留两类永久素材；题/答/解析由接口采集到 `data/knowledge-source/papers/`（不产手抄做题记录）。

| 文件类型 | 保留策略 |
|---------|---------|
| 解析与用户留言_*.md | ✅ 永久保留 |
| 用户笔记精华_*.md | ✅ 永久保留 |

---

## 注意事项

1. **本地是源头**：所有知识库内容必须先在本地完成，再同步飞书
2. **不要直接改飞书**：飞书知识库的修改应先改本地，再同步
3. **验证/同步不单独成文**：默认并入任务报告；如确需留档仅本地、不上传飞书
4. **冲突处理**：当用户留言与讲义冲突时，以讲义为准
5. **敏感信息**：用户留言中可能包含个人信息，整理时注意脱敏
