## 三、考点图谱为何不是"知识点关联"（证据链）

### 3.1 侦查路径（只读，未交卷、未点"练一练"）

- 页面：`/course/42660/knowledge-sketch`（15 章总览）、`/knowledge-sketch/detail`（关系图详情，顶部选章下拉切换章）。
- 交互形态：**左侧**是当前章下的分组/考点卡片（带 +/− 展开钮），点选某项后**右侧**用蓝色折线展开它的直接下级卡片；逐层 +/− 展开。视觉上像"关系网络"。

### 3.2 数据来源：唯一一棵层级树

- 全页唯一承载图谱数据的请求：`POST https://apigateway.gaodun.com/nice/transit/with-sid`（form-urlencoded 的 BFF 转发），下游真实接口 `ep-syllabus.gaodun.com/exam-syllabus/student/course/point`，入参 `{exam_syllabus_id, course_id}`，鉴权复用做题链路同一 `authentication: Basic <JWT>`，无额外签名。
- 响应 `result.content[]` 为 **15 个一级章**，每章 `knowledge_children[]` 为考点，**全课共 96 个考点**。

### 3.3 四条证据证明它只是"目录归属树"、无知识点横向关联

1. **严格两层、单祖先链**：按 `path`（如 `0|113476|113482|`）统计，真实节点只有 15 章 + 96 考点；每个考点祖先链唯一，**多父/跨挂考点数 = 0**（树，不是多对多图）。`path` 中间段是 76 个"虚拟分组"id，响应里无独立节点对象，仅渲染成左侧二级分组壳（如"印花税法"，其下"印花税"才是考点）。
2. **无关联字段**：除 `knowledge_children`/`content` 外，**没有任何承载"关联其它考点"的数组字段**。
3. **展开/悬停/点圆点不发新请求**：详情页逐级展开时 XHR 基本为空，右侧内容 100% 来自上面那一个 JSON，**没有点击后才加载的隐藏关联网络**。
4. **点进最底层叶子考点只有"做题任务"**：叶子详情显示掌握状态 + 考点任务（做题数/正确率/目标道数/练一练）；唯一额外接口 `GET /ep-paper/front/item/knowledge?knowledge_ids=..&course_id=..` 返回 `{knowledge_error_problem:{}, knowledge_favorite_problem:{}, error_total, favorite_total}`，即该考点的**错题/收藏题统计**，同样不是关联知识点；页面全文检索"相关/关联/前置/后续/相似/联动/依赖/推荐/区别/联系"**零命中**。

> 用户截图中"印花税旁列车辆购置税/车船税/印花税法"，是三个考点**同属一章**（章名即"车辆购置税法、车船税法和印花税法"）的**并列归属**，并非知识点之间互相引用。

### 3.4 结论

- 该组件是考纲**目录树的可视化展开**（左父右子、连线=归属），**不产出知识点关联**；逐个圆点遍历不会得到 JSON 之外的信息，工作量大且零收益，故不做。
- 若未来确需"知识点横向关联（税种交叉、前置依赖等）"，平台不提供，只能在知识生成阶段从**题面 / 官方解析 / 讲义文本**中提炼，届时另立任务，与本已否决的图谱无关。

### 3.5 给未来的检索备忘（防重复调研）

- 页面路由：`knowledge-sketch`、`knowledge-sketch/detail`；选章控件 `.knowledge-detail-syllabus-select`（antd Select）。
- 接口关键字：`nice/transit/with-sid`（BFF 表单转发 baseName/path/params）、`ep-syllabus`、`/exam-syllabus/student/course/point`、`/ep-paper/front/item/knowledge`；`examSyllabusId` 来自 `GET /ep-course/api/v1/front/course/{courseId}` 的 `courseSetting.examSyllabusId`。
- 官方/通用方向（如日后复核）：Chrome DevTools Protocol Network 域、Puppeteer `page.on('request'/'response')`、antd Select 浮层选项在 body 末尾 `.ant-select-item-option`。
