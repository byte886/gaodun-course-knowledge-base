## 2. 任务分解（DAG：依赖 / 并发 / 验收）

### S1 网盘补传（WORKFLOW 步骤6）— 解主要缺口
- **输入**：课程库03-38讲（压缩视频+讲义+transcript+docs_text）、data/knowledge-source/papers
- **动作**：`scripts/baidu_upload.py` / batch_upload，按本地目录结构在网盘 `/apps/CPA课程归档/高顿/CPA/课程库/【26考季】VIPCPA系列-税法（蔡俊峻老师）/` 下补传；**不上传**原始未压缩视频与技术过程文件
- **并发**：IO密集，2-3并发（WORKFLOW并发特性，禁flock、用xargs -P）
- **验收**：每讲上传后API list核对文件数与大小一致；最终网盘39讲齐全
- **回滚**：网盘误传可 delete（写操作，单讲确认）；不影响本地
- **依赖**：无，可最先启动

### S2 34章知识库重建（WORKFLOW 步骤7）— 阶段二核心
- **粒度**：讲01→讲34，官方全面精讲1:1，标题严格对齐COURSE_INDEX官方讲次，不合并/不重排
- **每讲原料（一次性集齐再生成，不做两阶段）**：
  1. 本讲 `transcript.md`（视频转写）
  2. 课件OCR：按 `knowledge-base/lecture-resource-map.json` 取（空docs讲取跨讲课件的docs_text）
  3. 题/答/解析：papers中 chapter 匹配"税法全面精讲NN-*"的全部套卷
  4. 用户笔记（如有；与讲义冲突以讲义为准）
- **每讲产出（严格按 KNOWLEDGE_BASE_TEMPLATE）**：知识拆解.md → 考试指导.md → 父节点README（含两个子节点链接+章节概述+重点+学习建议）
- **生成顺序**：知识拆解（客观知识）→ 考试指导（易错点/考点/口诀，基于拆解）→ 父节点
- **来源纪律**：剔除AI错题（旧UI BUG产物，非来源）；官方解析是标准答案权威；考点图谱不作来源（已否决）
- **验收（逐讲）**：三文件齐全；知识点有来源支撑、不臆造；父节点子链接有效；标题=官方讲次
- **依赖**：不依赖S1（本地生成），可与S1**并行**；但建议S1跑网盘时同步做S2，CPU/IO错开
- **并发**：生成是LLM密集型，逐讲串行保证质量；OCR/读取等IO预处理可批量

### S3 分讲同步飞书（WORKFLOW 步骤8）
- **时机**：每讲本地三文件生成并自检通过后即同步该讲（分讲同步，避免最后集中风险）
- **前置决策**：旧15章节点去留（见 D4），启动S3前必须拍板
- **动作**：lark-cli 建34讲节点树 → docs +update 写内容（stdin方式）→ 父节点写子链接；**禁止直接在飞书编辑**
- **验收**：每讲同步后 node-list 回查层级/父节点链接可点达、无空节点/重复节点（feishu-knowledge-base-maintenance SOP覆盖校验）
- **依赖**：S2对应讲完成
- **回滚**：节点可删（高风险，单讲确认）；本地是源头，可重推

### S4 考试指导速查手册（WORKFLOW 步骤7生成顺序第5步）
- **时机**：34讲全部完成后
- **内容**：横向汇总税率表、高频考点TOP10、易错点TOP10、跨税种对比
- **硬约束**：**只含通用知识点与应试指导，不包含具体指定业务的题目或场景要求**
- **同步**：覆盖飞书已有的"考试指导速查手册"节点

### S5 冲刺模考（WORKFLOW 步骤5特殊模式，最后做）
- **前置**：S2-S4全部完成（基础作业与知识库齐全后才做，符合学习逻辑）
- **对象**：3张48题冲刺模考卷（官网获取，papers当前未含）；题/标准答案也是知识来源
- **链路**：接口为主、UI仅登录与兜底（ADR-010、gaodun-exam-api）；进卷redo取题答→匹配→submit→exam-report回查；注意最小作答墙钟时长风控、低频拟人
- **产出**：3张卷题答入库 → 反哺/迭代知识库 → 更新速查手册 → 再次同步飞书
- **专项注意**：type=5/6主观计算大题按 gaodun-exam-api §2.3/§4.2（答案在解析文本；AI批改权益有限、不强依赖）

### S6 最终总同步 + 任务总结（步骤8/9）
- 全课程最后一次飞书结构总校验（节点树、父节点链接、独立文档、无孤岛）
- 对话内总结，不单独生成飞书报告；更新TASK_STATUS/BATCH/COURSE_INDEX为全完成

## 3. 依赖与并发总览

```
S1 网盘补传(03-38) ─────────────────────────────┐
                                                ├─→ S6 总同步+总结
S2 34章重建(讲01→34, 串行保质量) ─→ S3 分讲同步飞书 ┘
                                      │

                                      └─→ S5 冲刺模考(最后) ─→ 反哺知识库+更新S4+再同步
```
- **可并行**：S1（网络IO）与 S2（本地生成）同时跑，资源错峰
- **串行**：S2内部逐讲；S3跟随S2每讲；S4待S2完；S5待S2-S4完
- 调度遵循 WORKFLOW「多任务并发调度」+ task-planning-and-parallel-scheduling 方法论：子任务完成即通知调度、并发度以已实测结论为准（FunASR类CPU任务串行、网盘2-3并发）
