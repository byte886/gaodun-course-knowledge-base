# 活动文档目录（active）

> **文档类型**：Active（过程记录）
> **更新频率**：任务执行时实时更新
> **维护者**：AI自动维护
> **读者**：AI代理+人类（了解当前项目状态）

本目录存放项目的活动状态文档，包括任务状态、问题跟踪、课程索引、阶段作战计划等（验证结论并入任务报告，不在本目录单列）。

---

## 文档清单

| 文档 | 用途 |
|------|------|
| `TASK_STATUS.md` | 当前任务状态（进度、待办、完成状态） |
| `ISSUES.md` | 问题跟踪（已知问题、解决方案、状态） |
| `COURSE_INDEX.md` | 课程索引（所有课程的进度、位置、知识库链接） |
| `BATCH_TASK_STATUS.md` | 大任务状态（批量任务的进度、检查点） |
| `STAGE2_EXECUTION_PLAN.md` | 阶段二作战计划（步骤/依赖/并发/验收/回滚，启动后随执行更新） |

---

## 使用原则

1. **实时更新**：任务执行时实时更新状态文档
2. **接手任务前先读**：接手任务前，先读 TASK_STATUS.md 了解当前状态
3. **问题及时记录**：发现问题时，及时记录到 ISSUES.md
4. **完成后清理**：任务完成后，更新状态为已完成，清理临时文件
5. **验证留痕**：验证为必做动作，但结论并入任务输出/《任务报告》，默认不单独成文、不在本目录单列
